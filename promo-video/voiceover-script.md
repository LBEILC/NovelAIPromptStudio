# 16:9 宣传 Demo 口播脚本

## 合成配置

- 引擎：GPT-SoVITS v2ProPlus
- GPT 权重：`Bagpipe_CN_v2ProPlus-e15.ckpt`
- SoVITS 权重：`Bagpipe_CN_v2ProPlus_e8_s216.pth`
- 参考音频：`ref_01_neutral.wav`
- 参考语气：自然、日常说明
- 语速：`1.08`
- 随机种子：`1234`
- 输出：32kHz 单声道 WAV

配音为 AI 合成，仅用于 NovelAI Prompt Studio 宣传 Demo。

## 分镜文案

1. **开场**
   - NovelAI 图片里的 Prompt，不该一直困在 metadata 里。
2. **工作台解析**
   - 把图片拖进 NovelAI Prompt Studio，Base Prompt、Character Prompt 和 Undesired Content，会自动拆分成清晰的 Tag。
3. **编辑与复制**
   - 你可以按区域和类别筛选，查看翻译，调整权重，再一键复制需要的 Prompt。
4. **Vibe 恢复**
   - 如果图片带有内嵌 Vibe，软件也会只读识别它的强度和 Information Extracted，并恢复导出为可以继续使用的 Vibe 文件。
5. **图片库**
   - 批量导入生成图片，按文件名、Tag 或译名搜索，相同 Prompt 的结果还会自动分组。
6. **本地优先**
   - 所有整理数据都保存在本地，原图保持只读。
7. **收尾**
   - NovelAI Prompt Studio，让 Prompt 真正回到创作流程里。
