# 工作台标签页预览与视图状态手工验证

## 待验证变更

工作台标签页悬停图片预览、每标签独立保存筛选/分组/语言状态，以及右键编辑 Tag 时不再清除当前筛选。

## 目标操作系统

Windows 10/11。

## 前置条件

- 已执行 `npm ci`。
- 准备至少两张可由工作台打开的 PNG、JPG 或 WEBP 图片，其中至少一张包含 NovelAI Prompt 元数据。
- 建议其中一张图片使用较长文件名，以检查标签和预览标题截断。
- 使用 `npm run dev` 启动应用。

## 验证步骤

1. 在工作台中打开至少两张图片，并停留在任意一个标签页。

   预期结果：每张图片各自显示为一个工作台标签，标签切换、关闭和未保存修改标记均保持原有行为。

   实际结果：

2. 将鼠标停留在一个未激活标签的标题区域约半秒，不要点击。

   预期结果：标签下方出现预览卡片，显示对应图片、图片名、分辨率和 Tag 数；仅悬停不会切换当前标签。

   实际结果：

3. 在多个标签之间快速移动鼠标，然后将鼠标移出标签栏。

   预期结果：短暂划过不会立即弹出大量预览；停留后只显示当前悬停标签的预览；移出后预览正常关闭，且不被标签栏裁切。

   实际结果：

4. 在标签 A 中设置非默认搜索词、Prompt 类型、Prompt 区域、Tag 分类、分组方式和显示语言；切换到标签 B，并设置另一组不同条件。

   预期结果：标签 A 与标签 B 分别显示各自设置的筛选、分组和语言状态。

   实际结果：

5. 使用鼠标以及 `Ctrl + Tab` / `Ctrl + Shift + Tab` 在标签 A、B 之间往返切换。

   预期结果：每次切回标签时都恢复该标签自己的搜索词、筛选、分组方式和显示语言，不会恢复默认值或串用另一个标签的状态。

   实际结果：

6. 切换到图片库或设置页，再返回工作台。

   预期结果：工作台各标签的视图状态保持不变。

   实际结果：

7. 保留工作台标签并正常退出应用，然后重新启动应用。

   预期结果：工作台会话恢复后，各标签的视图状态仍与退出前一致。

   实际结果：

8. 在已应用筛选的标签中右键一个当前可见的 Tag，选择“编辑”。

   预期结果：该 Tag 的编辑浮层正常打开；当前搜索词、筛选、分组方式和显示语言均不改变。

   实际结果：

9. 分别使用标签关闭按钮、标签右键菜单和鼠标中键关闭标签。

   预期结果：三种关闭方式均保持可用，悬停预览不会拦截关闭操作；存在未保存修改时仍显示原有确认流程。

   实际结果：

10. 在浅色与深色主题下重复悬停预览，并将窗口缩窄后检查长文件名标签。

    预期结果：预览卡片在两种主题下均清晰可读；窄窗口中不会溢出屏幕；长名称正确截断，图片保持完整比例。

    实际结果：

## 总体结果

通过。标签页预览、每标签视图状态保留和右键编辑行为均未发现功能问题。

## 发现的问题

竖图在横向预览区域中的可视尺寸偏小，建议将预览图片区调整为正方形，并保持图片完整显示、不裁切。
