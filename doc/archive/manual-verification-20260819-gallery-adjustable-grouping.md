# 图片库渐进式自动分组手动验证

## 验证对象

- 功能提交：`bf54609 feat: add adjustable gallery grouping`、`0cbaa4c feat: add progressive gallery grouping controls`
- 目标操作系统：Windows 11（本轮用户验证）；macOS 复验记录在 `coordination/MACOS.md`

## 前置条件

1. 已拉取包含 `0cbaa4c` 的最新 `main`，并正常启动桌面应用。
2. 图片库中准备以下可辨认的 NovelAI 图片；可以使用现有图片，不要求重新生成：
   - 至少两张完整 Prompt、Vibe、模型完全相同，仅 Seed 不同的图片。
   - 至少两张完整 Prompt 和模型相同、Vibe 不同的图片。
   - 至少两张 Base Prompt 与 Base Undesired Prompt 相同，但角色 Prompt 或角色位置不同的图片。
   - 两组 Base Prompt 大部分 Tag 相同、少量 Tag 不同的图片，用于观察相似度阈值。
   - 至少一张 Base Undesired Prompt 明显不同的图片。
   - 至少一张生成模型不同的图片。
3. 如果旧版本中为一个图片组设置过头图，保留该图库用于验证迁移；没有旧头图时可跳过步骤 9 的迁移部分，但仍需验证新头图持久化。

## 验证步骤

1. 打开图片库，检查工具栏并缩窄窗口到应用允许的最小宽度。
   - 预期结果：工具栏只常驻一个带当前状态的“分组”按钮，不再常驻分组滑杆和跨 Vibe 开关；缩略图大小滑杆、搜索、排序和图片计数仍可用，窄窗口下自然换行且不遮挡。
   - 实际结果：

2. 点击“分组”按钮，并用鼠标、键盘分别检查设置浮层。
   - 预期结果：浮层列出“全部分开 / 完整 Prompt / 基础 Prompt / 相似 Prompt”四个互斥选项及简短说明，底部有独立“跨 Vibe 合并”开关；浮层不会被窗口边缘裁切，按 Esc 或点击外部可关闭，关闭后焦点合理返回。
   - 实际结果：

3. 选择“全部分开”。
   - 预期结果：每张图片各自成为一组；“跨 Vibe 合并”开关禁用；工具栏按钮显示“全部分开”，图片计数不变，组数等于图片数。
   - 实际结果：

4. 选择“完整 Prompt”，保持“跨 Vibe 合并”关闭，然后再开启该开关。
   - 预期结果：关闭时，只有完整 Prompt、Vibe、模型相同且仅 Seed 等非分组参数不同的图片合并；开启后，完整 Prompt 和模型相同的不同 Vibe 图片进一步合并；不同模型始终不合并，按钮文字同步反映状态。
   - 实际结果：

5. 选择“基础 Prompt”，先关闭再开启“跨 Vibe 合并”。
   - 预期结果：关闭时，Base Prompt、Base Undesired Prompt、Vibe 和模型相同的图片合并，即使角色 Prompt、角色 Undesired、角色顺序或位置不同；开启后允许不同 Vibe 进一步合并。Base Undesired 不同或模型不同的图片始终分开。
   - 实际结果：

6. 选择“相似 Prompt”，检查随后才出现的相似度控件。
   - 预期结果：只有该模式显示 70%–95%、步长 5% 的相似度滑杆；工具栏按钮显示当前百分比。把阈值从 95% 逐步降低到 70% 时，分组只会保持或合并，不会反向拆分；相邻图片的间接相似不会把首尾明显不同的图片链式并入同一组。
   - 实际结果：

7. 在“相似 Prompt”下切换“跨 Vibe 合并”，并观察 Base Prompt、Base Undesired Prompt、Vibe 与模型边界。
   - 预期结果：相似度基于 Base Prompt 与 Base Undesired Prompt，忽略角色 Prompt、角色顺序、位置和 NovelAI 语法差异；正向 Base Prompt 影响更大，但明显不同的 Base Undesired 仍会降低相似度。关闭跨 Vibe 时不同 Vibe 不合并，开启后才允许合并；不同模型在任何阈值下都不合并。
   - 实际结果：

8. 在各模式与阈值间来回切换，同时保持右侧详情打开并选择若干组。
   - 预期结果：切换立即生效且无闪退；当前详情图片仍保持打开并归入新组；已经不再存在的组选择会安全清除，不会把批量操作错误应用到旧组。
   - 实际结果：

9. 回到“完整 Prompt + 跨 Vibe 合并关闭”，在一个多图组中把非当前头图设为头图；随后切换到其他模式再切回，并重启应用。
   - 预期结果：只有该精确模式显示“设为头图”；基础、相似等动态分组不显示该入口，且默认显示最新图片；切回精确模式以及重启后，所设头图仍恢复。旧版本头图只迁移到包含原头图的精确子组，不会复制到其他 Vibe 或模型子组。
   - 实际结果：

10. 在动态分组模式下搜索一个位于组内、但不是该组最新图片的文件名或 Tag。
    - 预期结果：结果卡片临时显示实际命中的组内图片，而不是仍显示最新图片；悬停文件名、擦动预览、单击详情和双击工作台仍与指针所在成员一致。清除搜索后恢复动态组默认展示。
    - 实际结果：

11. 选择一个非默认组合，例如“相似 Prompt 80% + 跨 Vibe 合并开启”，切换到工作台再返回图片库，然后完全退出并重新启动应用。
    - 预期结果：分组模式、相似度阈值和跨 Vibe 选项均被持久化；重新进入后按钮状态、组数和分组结果一致。
    - 实际结果：

12. 分别在浅色、深色主题下检查浮层、单选项、开关、滑杆、键盘焦点和文字对比度。
    - 预期结果：选中、悬停、禁用和焦点状态清晰；单选项、开关和相似度滑杆均可通过键盘到达和操作；没有低对比度、裁切、意外横向滚动或浮层遮挡异常。
    - 实际结果：
