# Tag 悬停预览手工验证

## 待验证变更

将 Tag 原生 `title` 提示替换为 Lobe TooltipGroup 承载的结构化悬停预览卡。预览固定展示分类、区域、权重、语法警告和当前操作提示，并根据显示语言只补充 Tag 本身未展示的内容：原文模式显示翻译，翻译模式显示原文，对照模式不再重复两者。同时保持点击编辑、右键菜单、拖拽排序与键盘排序行为。

## 目标操作系统

Windows 10/11。

## 前置条件

- 准备包含已翻译、未翻译、非默认权重和语法警告 Tag 的图片。
- 使用 `npm run dev` 启动应用并进入工作台。

## 验证步骤

1. 选择“原文”模式，依次悬停已翻译和未翻译的 Tag。

   预期结果：约 320ms 后显示结构化预览卡；卡片只显示翻译，不重复原文；未翻译 Tag 明确显示“暂无翻译”，不再出现浏览器原生黑色提示框。

   实际结果：通过，用户反馈未发现问题。

2. 选择“翻译”模式并悬停 Tag。

   预期结果：卡片只显示原文，不重复翻译；未翻译而回退显示原文的 Tag，卡片仍只显示原文。

   实际结果：通过，用户反馈未发现问题。

3. 选择“对照”模式并悬停 Tag。

   预期结果：卡片不显示原文和翻译，仅保留分类、区域、非默认权重、语法警告和操作提示。

   实际结果：通过，用户反馈未发现问题。

4. 悬停不同分类、区域和权重的 Tag。

   预期结果：顶部分类色点、分类名称、区域名称与非默认权重正确；长原文和翻译能够换行，卡片不溢出窗口。

   实际结果：通过，用户反馈未发现问题。

5. 悬停带语法警告的 Tag。

   预期结果：预览中出现独立的黄色警告区，文字完整且不会与操作提示混在一起。

   实际结果：通过，用户反馈未发现问题。

6. 在多个相邻 Tag 之间连续移动鼠标，并分别检查浅色和深色主题。

   预期结果：共享 Tooltip 平滑切换内容和位置；颜色、边框、阴影和文字层级与标签页预览协调。

   实际结果：通过，用户反馈未发现问题。

7. 分别执行点击编辑、右键打开菜单、鼠标拖拽、`Alt + 方向键` 排序和多选模式点击。

   预期结果：原有操作全部正常；悬停预览不会遮挡编辑器或右键菜单，也不会造成误点击或拖拽失效；多选时底部提示变为“点击选择”。

   实际结果：通过，用户反馈未发现问题。

通过。用户于 2026-08-14 确认功能没有问题。
