# DSO 离线 Tag 词典与分类手动验证

## 受测变更

- 变更：内置固定版本的 DanbooruSearchOnline 中文 Tag 数据与 Tag Group 分类；保留 Danbooru 在线画师验证；未配置 AI 时允许返回完整或部分离线结果。
- 目标操作系统：Windows 10/11 x64；macOS Intel / Apple Silicon。

## 前置条件

- 使用包含本次变更的构建。
- 准备一张可在工作台打开的图片，Prompt 至少包含 `1girl`、`blue hair`、`school uniform`、`smile`、`dutch angle`、`white background`。
- 另准备一个 DSO 不收录的测试 Tag，例如 `novelai prompt studio unknown phrase`。
- 在设置 → AI 服务中清空默认模型，确保本轮没有可调用的 AI 模型。

## 验证步骤

1. 打开测试图片，在 Prompt 总览确认顶部按钮和单 Tag 菜单使用“翻译与分类”而不是“AI 翻译”。
   - 预期结果：入口文案明确离线功能可用；按钮、菜单和窄窗口布局没有截断或错位。
   - 实际结果：

2. 保持 AI 模型为空，点击“翻译与分类”。
   - 预期结果：操作成功而不是提示“请先选择模型”；上述常用 Tag 获得中文译名，并分别进入角色组成、外貌身体、服装配饰、动作表情、镜头光影和环境背景。
   - 实际结果：

3. 对 `novelai prompt studio unknown phrase` 执行“翻译与分类”。
   - 预期结果：操作不失败，Toast 说明仍有 Tag 缺少译文或分类；未知 Tag 保持原文和“未分类”，不会伪造结果。
   - 实际结果：

4. 手工修改 `blue hair` 的译文和分类，再次执行“翻译与分类”。
   - 预期结果：用户译文与分类保持不变，不被 DSO、规则或缓存覆盖。
   - 实际结果：

5. 对一个已知但没有 `artist:` 前缀的 Danbooru 画师名执行“翻译与分类”。
   - 预期结果：联网可用时仍通过 Danbooru 验证为“画师年代”；DSO 不会覆盖或阻断原画师验证路径。断网时操作仍安全返回，不将未知名字误判为画师。
   - 实际结果：

6. 打开设置 → Tag 缓存，按来源选择“DSO 内置词典”，并搜索刚处理的中文译名。
   - 预期结果：来源筛选可用，DSO 译文和分类来源清楚显示；编辑后来源切换为“用户修改”。
   - 实际结果：
