# 工作台添加角色按钮居中手工验证

## 待验证变更

将“暂无角色 Prompt”按钮的水平居中职责移到独立外层容器，避免 Lobe Button 在开发环境与生产构建中的样式注入顺序影响按钮位置。

## 目标操作系统

Windows 10/11。

## 前置条件

- 打开一张没有 Character Prompt 的图片。
- 确保工作台处于“按结构”视图，并且区域筛选不是“Base”。
- 分别准备 `npm run dev` 启动的测试版和本次提交生成的正式安装包。

## 验证步骤

1. 在测试版中滚动到 Prompt 内容底部，观察“暂无角色 Prompt”按钮。

   预期结果：按钮在右侧内容区域内水平居中，两侧空白基本对称。

   实际结果：通过，与预期一致。

2. 安装并启动本次提交生成的正式包，在相同图片和筛选条件下观察该按钮。

   预期结果：正式包中的按钮同样水平居中，位置与测试版一致，不再靠近内容区域左侧。

   实际结果：通过，与预期一致。

3. 分别将应用窗口调整为较宽和较窄尺寸。

   预期结果：宽窗口下按钮最大宽度保持为 760px 并居中；窄窗口下按钮随内容区域缩小，左右保留合理间距且不溢出。

   实际结果：通过，与预期一致。

4. 分别在浅色和深色主题下点击按钮。

   预期结果：按钮边框、文字、图标与悬停状态正常；点击后仍能正常添加 Character Prompt。

   实际结果：通过，与预期一致。

## 总体结果

通过。添加 Character Prompt 按钮在开发版、正式包、不同窗口宽度和两种主题下均正确居中且功能正常。

## 发现的问题

无。
