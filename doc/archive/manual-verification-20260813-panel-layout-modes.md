# 工作台与图片库侧栏布局模式手动验证

## 验证对象

- 变更：工作台左侧图片面板使用稳定布局收起，避免收起过程中压缩内部元素；图片库右侧预览面板默认浮动显示，并可通过图钉按钮固定为分栏。
- 首次验证提交：`2100f4f`。
- 首次验证结果：未通过。工作台左侧稳定布局外壳在宽屏下按 `34vw` 占位，内部面板受 `560px` 最大宽度限制，切换页面后会在两者之间留下空白；拖动分隔线后空白暂时消失。
- 首次修复提交：`734cf1c`。默认宽度改为限制在 `280px` 至 `560px`，解决稳定布局外壳与内部面板宽度不同产生的静态空白。
- 第二次验证结果：未通过。页面切换后首次收起时，内部图片仍随外壳宽度缩小；手动调宽后的第一次收起缺少完整动画，再次展开和收起后才符合预期；图片库预览面板同样复现。
- 第二次修复提交：`dbfa8af`。两个面板在首次渲染时直接根据窗口宽度计算并传入受控像素宽度，不再等到用户拖拽后才从相对宽度切换为像素宽度。
- 第三次验证结果：通过。工作台与图片库面板首次收起、拖拽后首次收起及页面切换后的动画和内容尺寸均恢复正常。
- 宽度记忆提交：`f300cb7`。分别记忆工作台左侧面板和图片库右侧预览面板的用户调整宽度，在切换页面和重新启动应用后恢复。
- 目标操作系统：Windows 11。

## 前置条件

- 已执行 `npm ci`、`npm test` 和 `npm run build`。
- 工作台中至少打开一张包含 Prompt 的图片。
- 图片库中至少有 8 组图片，能够明显观察网格列数和滚动位置。

## 验证步骤

1. 启动应用并进入工作台，记录左侧图片面板中图片、文件名和 Vibe 信息的展开状态，然后点击侧栏收起手柄。
   - 预期结果：左侧面板和右侧编辑区之间没有空白；左侧面板作为一个整体平滑收起；收起过程中图片、文件名和 Vibe 不会先被横向压缩或反复换行；右侧编辑区同步获得释放的空间。
   - 实际结果：通过。侧栏整体收起，内部内容未被压缩，编辑区正常扩展。

2. 再次点击侧栏手柄展开左侧图片面板，并拖动分隔线改变面板宽度后重复收起和展开。
   - 预期结果：面板恢复到用户调整后的宽度；手动调宽时内容正常响应，点击收起时内部布局保持稳定；图片始终位于展示区域中央；切换到图片库再返回工作台后，侧栏边缘仍与编辑区贴合，不重新出现空白。
   - 实际结果：通过。调宽、收起、展开和页面往返切换均正常，没有重新出现空白。

3. 进入图片库，滚动到网格中部并记住几张相邻图片的位置，然后点击其中一张打开预览。
   - 预期结果：右侧预览默认以浮动方式覆盖在网格上方；网格列数、图片排列和纵向滚动位置均不改变；被选中的图片组保持高亮。
   - 实际结果：通过。浮动预览未改变网格列数、排列与滚动位置，选中状态正常。

4. 在浮动预览顶部点击“固定为分栏”图钉按钮，并拖动预览面板左侧分隔线。
   - 预期结果：图钉显示为已固定状态，预览切换为固定分栏并占用布局宽度；网格按剩余空间正常重排；预览宽度仍可在原有限制范围内调整。
   - 实际结果：通过。预览可固定为分栏并正常拖动宽度，网格按剩余空间布局。

5. 点击“取消固定，浮动显示”按钮。
   - 预期结果：预览在不关闭、不丢失当前图片的情况下恢复浮动；图片网格恢复完整可用宽度和原有排列逻辑；图钉状态同步更新。
   - 实际结果：通过。取消固定后恢复浮动，当前图片与网格状态均保留。

6. 在图片预览中进入重命名状态，并分别检查深色和浅色主题。
   - 预期结果：重命名输入框、保存/取消按钮和图钉按钮均完整显示且可以操作；浮动预览边界清晰，没有异常透明、遮挡或文字溢出。
   - 实际结果：通过。重命名控件、图钉按钮及深浅主题显示正常。

7. 缩窄应用窗口，分别测试浮动、固定、收起和展开状态。
   - 预期结果：两个侧栏均不溢出应用工作区；主内容保持可滚动和可操作；侧栏切换按钮保持可见且键盘焦点清晰。
   - 实际结果：通过。窄窗口下侧栏和主内容仍可正常操作，未发现异常溢出。

8. 分别把工作台左侧面板和图片库右侧预览面板拖到两个容易区分的宽度，然后在工作台与图片库之间往返切换。
   - 预期结果：两个页面各自恢复刚才调整的宽度，互不覆盖；首次展开和收起动画仍然完整，内容尺寸保持稳定。
   - 实际结果：通过。两个页面分别恢复各自宽度，动画与内容尺寸保持正常。

9. 保持两个面板为调整后的宽度，完整退出并重新启动应用，再分别进入工作台和图片库。
   - 预期结果：两个面板分别恢复上次退出前保存的宽度；如果保存值缺失、损坏或越界，则安全回退或限制在允许范围内，不影响页面使用。
   - 实际结果：通过。完整退出并重新启动后，两个面板均恢复各自保存的宽度。

## 验证结论

- 总体结果：通过。
- 发现的问题：无。
