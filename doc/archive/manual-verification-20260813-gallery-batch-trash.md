# 图片库批量移入回收站手工验证

## 验证信息

- 变更：修复图片库多选后点击“移入回收站”时，点击事件被误当作图片 ID 列表的问题；同时保护批量恢复和批量永久删除操作不接收点击事件参数
- 目标操作系统：Windows 11
- 前置条件：已完成 `npm ci`；图片库中至少有 2 个可供测试的图片组；测试图片允许移入回收站，其中至少 1 张允许永久删除
- 数据提醒：第 6 步会永久删除测试图片且不可恢复，请仅使用可丢弃的测试数据；如果不准备验证永久删除，请在“实际结果”中注明跳过原因

## 验证步骤

1. 运行 `npm run dev`，进入“图片库”的“全部”视图，选择至少 2 个图片组。
   - 预期结果：页面出现批量操作栏，已选组数和图片数与所选内容一致，“移入回收站”按钮可点击。
   - 实际结果：通过（用户确认）。

2. 点击“移入回收站”，检查确认对话框，然后点击“取消”。
   - 预期结果：确认对话框正常打开，文案中的组数和图片数正确；取消后图片仍在原视图中，当前选择未被错误处理，应用无报错。
   - 实际结果：通过（用户确认）。

3. 再次点击“移入回收站”，在确认对话框中点击“移入回收站”。
   - 预期结果：所选图片全部从当前视图移除，显示成功提示；没有出现参数、IPC 或批量操作错误。
   - 实际结果：通过（用户确认）。

4. 切换到“回收站”视图，确认刚才移入的图片均存在；多选其中至少 2 个图片组并点击“恢复”。
   - 预期结果：选中的图片全部从回收站移除并恢复到图片库，显示成功提示；批量操作没有失效。
   - 实际结果：通过（用户确认）。

5. 返回“全部”视图，将至少 1 个可丢弃的测试图片组再次移入回收站，然后在“回收站”视图中多选该组并点击“永久删除”；先在确认对话框中取消。
   - 预期结果：永久删除确认对话框正常打开；取消后测试图片仍保留在回收站中。
   - 实际结果：通过（用户确认）。

6. 再次点击“永久删除”并确认。
   - 预期结果：选中的测试图片从回收站移除，显示成功提示；重新进入回收站后图片不会再次出现。
   - 实际结果：通过（用户确认）。

## 验证结论

- 总体结果：通过。批量移入回收站、恢复与永久删除均工作正常。
- 发现的问题：无。
