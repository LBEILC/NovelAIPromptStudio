# 工作台标签页自适应预览手工验证

## 待验证变更

工作台标签页悬停预览根据原图比例自动调整图片区和卡片宽度：常规竖图变窄、变高，横图变宽、变矮，方图保持方形。预览最大宽度为 360px、最大高度为 400px；极端比例保留最小可读尺寸并使用灰色背景补足。

## 目标操作系统

Windows 10/11。

## 前置条件

- 准备至少一张常规竖图、一张横图和一张方图。
- 使用 `npm run dev` 启动应用，并在工作台中分别打开这些图片。

## 验证步骤

1. 依次悬停常规竖图、横图和方图标签。

   预期结果：竖图预览明显变窄、变高；横图预览变宽、变矮；方图预览保持方形。三种图片均完整显示、不裁切、不拉伸。

   实际结果：

2. 在不同图片标签间快速移动鼠标并停留。

   预期结果：浮层在切换图片时平稳更新为对应比例，不影响标签切换、关闭和横向滚动。

   实际结果：

3. 缩窄应用窗口，并分别在浅色、深色主题下检查预览。

   预期结果：预览不溢出窗口；极端比例图片不会让卡片窄到无法阅读或高到超出可用空间；必要的空余区域使用灰色背景。

   实际结果：

## 总体结果

基本通过：图片比例自适应和完整显示符合预期，但预览整体尺寸偏大。

## 发现的问题

最大宽度 360px、最大高度 400px 的预览在当前工作台中视觉占用偏大，建议整体缩小约 10%。
