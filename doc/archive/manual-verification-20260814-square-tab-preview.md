# 工作台标签页正方形预览手工验证

## 待验证变更

将工作台标签页悬停预览的图片区由横向区域调整为正方形，图片保持完整比例显示，不裁切、不拉伸。

## 目标操作系统

Windows 10/11。

## 前置条件

- 准备至少一张明显的竖图和一张横图。
- 使用 `npm run dev` 启动应用，并在工作台中分别打开两张图片。

## 验证步骤

1. 将鼠标停留在竖图标签上约半秒。

   预期结果：出现正方形预览区域；竖图完整显示、不裁切、不拉伸，相比原横向区域具有更大的可视尺寸。

   实际结果：失败。正方形容器已经显示，但竖图仍按宽度缩放，底部超出容器后被裁切，无法完整看到。

2. 将鼠标移到横图标签并停留约半秒。

   预期结果：横图完整显示、不裁切、不拉伸，图片上下可留有必要空白。

   实际结果：

3. 缩窄应用窗口，并分别在浅色、深色主题下重复查看预览。

   预期结果：预览卡片不溢出窗口，图片和文字在两种主题下均清晰可见。

   实际结果：

## 总体结果

失败。

## 发现的问题

图片元素的固有尺寸没有被正方形容器正确约束，`object-fit: contain` 未形成预期的完整缩放效果；需要限制图片最大宽高并使用自动宽高。
