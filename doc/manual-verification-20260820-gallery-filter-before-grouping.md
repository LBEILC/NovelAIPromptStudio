# 图片库筛选优先与组合筛选手动验证

## 验证对象

- 功能提交：`55fe1e4 feat: filter gallery images before grouping`
- 目标操作系统：Windows 11（本轮用户验证）；macOS 复验记录在 `coordination/MACOS.md`

## 前置条件

1. 已拉取包含 `55fe1e4` 的最新 `main`，并正常启动桌面应用。
2. 图片库中准备以下可辨认的图片；可以使用现有图片：
   - 至少两张在“相似 Prompt”下会进入同一组的图片，其中只有一张包含 `bagpipe` Tag。
   - 至少两张分别使用不同模型的图片。
   - 至少两张分别带有不同 Vibe 的图片，以及一张不带 Vibe 的图片。
   - 至少两张在不同日期导入的图片。
3. 为避免误操作，批量收藏测试结束后恢复原状态；不需要执行永久删除。

## 验证步骤

1. 选择“相似 Prompt”分组，确认包含 `bagpipe` 和不包含 `bagpipe` 的两张图片在未筛选时处于同一图组，然后搜索 `bagpipe`。
   - 预期结果：只保留实际包含 `bagpipe` 的图片；结果图组的成员数、悬停擦动、序号、右侧详情和键盘左右导航都不再包含未命中的图片。
   - 实际结果：

2. 清除搜索词。
   - 预期结果：完整图片集合重新参与分组，原图组及其全部成员恢复；搜索期间没有修改图片、头图或分组设置。
   - 实际结果：

3. 检查工具栏中的“筛选”按钮并打开浮层。
   - 预期结果：未启用高级筛选时按钮不显示数量；浮层包含“包含 Tag、排除 Tag、模型、Vibe、导入时间”，界面紧凑且没有把这些控件常驻在工具栏。
   - 实际结果：

4. 在“包含 Tag”中选择两个 Tag，分别切换“全部”和“任意”。
   - 预期结果：“全部”只显示同时包含两个 Tag 的图片，“任意”显示至少包含其中一个 Tag 的图片；候选项可搜索，显示 Tag/译名和当前图库范围中的图片数量。
   - 实际结果：

5. 添加一个“排除 Tag”，并与包含 Tag 同时使用。
   - 预期结果：命中排除 Tag 的图片始终不显示；排除条件与包含条件同时生效。
   - 实际结果：

6. 选择一个或多个模型，并与 Tag 条件组合。
   - 预期结果：同一字段选择多个模型时满足任意一个即可；模型筛选与 Tag 筛选之间必须同时满足；未知模型在存在时可以单独选择。
   - 实际结果：

7. 分别选择一个具体 Vibe、“无 Vibe”和多个 Vibe。
   - 预期结果：具体 Vibe 使用稳定的短指纹和图片数量区分；“无 Vibe”只显示没有 Vibe 的图片；多选时满足任意一个 Vibe 即可，并继续与其他字段同时生效。
   - 实际结果：

8. 依次检查“今天、最近 7 天、最近 30 天、最近 90 天、今年、自定义范围”。
   - 预期结果：时间按本地导入日期筛选；相对范围包含今天，自定义起止日期均包含当天；只填写一侧日期时可作为开放范围使用。
   - 实际结果：

9. 同时输入搜索词，并启用 Tag、模型、Vibe和时间条件。
   - 预期结果：搜索与所有高级筛选走同一套逐图筛选逻辑；不同筛选项之间同时满足，筛选按钮显示激活的高级筛选维度数量，点击“清除”只清除高级筛选并保留搜索词。
   - 实际结果：

10. 在筛选结果中选择一个图组，然后改变任意搜索或筛选条件。
    - 预期结果：已有批量选择立即清除，避免相同图组 ID 在条件变化后扩大操作范围；重新选择后的图片计数只包含当前可见成员，收藏等批量操作不会影响被筛掉的成员。
    - 实际结果：

11. 打开一张图片的右侧详情，然后添加一个会排除当前图片、但仍保留其他图片的条件。
    - 预期结果：详情切换到当前结果中的可见成员；组内导航只遍历可见成员。若没有任何匹配图片，详情安全关闭并显示“没有匹配的图片”空状态。
    - 实际结果：

12. 保持筛选条件，切到工作台再返回图片库；随后切换“全部 / 收藏 / 回收站”图库范围。
    - 预期结果：普通页面切换保留当前搜索和筛选；切换图库范围会清除临时搜索、筛选、选择和详情，避免旧范围条件造成误解。
    - 实际结果：

13. 在浅色和深色主题、最小窗口宽度下检查筛选浮层，并使用键盘操作按钮、Tag 选择、模型、Vibe、时间和日期输入。
    - 预期结果：浮层保持在窗口内并可滚动；控件不会裁切或造成横向滚动；选中、禁用、焦点和激活状态清晰，键盘可以到达和操作所有筛选项。
