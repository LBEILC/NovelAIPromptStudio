# 动效令牌精修人工验证

## 验证对象

- 变更：统一页面切换、工作台 Tab、Tooltip、图库悬浮文件名与加载反馈的动效令牌，并保留减弱动效和关闭动效降级。
- 目标操作系统：Windows 11

## 前置条件

- 已检出包含本文件及关联动效源码的提交。
- 已执行 `npm ci`。
- 使用 `npm run dev` 启动桌面应用。
- 工作台至少打开两个图片 Tab；图库包含足以滚动的一批图片，并至少有一张能显示悬浮文件名的卡片。
- Windows“动画效果”保持日常使用设置；涉及减弱动效的步骤会单独说明。

## 验证步骤

1. 在“设置 → 外观”中将“动效”设为“完整”，依次从工作台切换到图库、设置，再返回工作台。
   - 预期结果：每个新页面以约 250 毫秒的短距离上移动、淡入和轻微去模糊进入；位移克制，结束时文字和图片完全清晰，不出现闪白、残留模糊或布局跳动。
   - 实际结果：

2. 在工作台、图库和设置之间快速连续切换至少 10 次，并在动画未结束时改变目标页面。
   - 预期结果：页面切换可以及时打断并响应最新选择；最终页面完全清晰、位置正确且可交互，不会叠加动画、卡住透明页面或遗留模糊滤镜。
   - 实际结果：

3. 在工作台的多个图片 Tab 之间切换，并快速往返选择相邻与不相邻 Tab。
   - 预期结果：选中指示器约 250 毫秒平滑移动和调整尺寸，连续操作时保持连贯且不会明显滞后；Tab 内容切换、关闭和拖拽排序行为不受影响。
   - 实际结果：

4. 将指针依次停留在工作台 Tag 及 Prompt 总览中的多个 Tag 上，再立即移出。
   - 预期结果：Tooltip 在约 80 毫秒意图延迟后出现，移出时立即开始关闭；快速掠过时不会产生长时间滞后的浮层，键盘焦点、复制和编辑操作保持正常。
   - 实际结果：

5. 在图库中将指针停留在宽度足以显示文件名的图片卡片上，然后移出并快速划过多张卡片。
   - 预期结果：卡片内文件名以约 150 毫秒平稳淡入和轻移，移出时自然消失；文件名不截获指针，图片悬浮预览仍保留原有意图延迟且不会闪烁或错配图片。
   - 实际结果：

6. 触发图库首次加载、筛选更新和大图加载，观察旋转图标与加载光带。
   - 预期结果：旋转图标保持匀速连续，加载光带以线性速度扫过，不在循环首尾明显加速、减速或顿挫；加载完成后反馈及时消失。
   - 实际结果：

7. 在深色和浅色主题下重复步骤 1、3、4、5，检查所有动效相关表面。
   - 预期结果：两种主题中的时序和运动一致；文字、图标、图片、Tab 指示器及 Tooltip 没有颜色闪变、边框残影或透明度异常。
   - 实际结果：

8. 将应用“动效”设为“关闭”，重复页面切换、Tab 切换和图库悬浮；再将应用设为跟随系统减弱动效，并启用 Windows 减弱动画偏好后重复。
   - 预期结果：空间位移、去模糊、Tab 滑动与悬浮过渡直接完成或缩短至不可感知；页面始终清晰可用，Tooltip 内容和加载状态仍能正确显示，不因禁用动效而缺失功能。
   - 实际结果：

9. 在包含较多缩略图的图库和显示大图的工作台之间连续切换并滚动，观察输入响应和帧率。
   - 预期结果：页面轻微模糊过渡不会造成明显掉帧、长时间输入阻塞或图片重排；动画结束后滚动、选择、预览与快捷操作均正常。
