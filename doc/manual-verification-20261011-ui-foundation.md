# 004 基础组件层：Windows 手动验收

- 待验证变更：随本文件提交的 `[工程] 实现基础组件层与独立验收工具`。
- 目标系统：Windows；macOS 人工验收按项目决定暂停。
- 状态：待用户执行。自动测试和离屏截图不代表以下交互已经人工验证。
- 前提：依赖已安装，运行 `npm run dev:ui`，打开输出的 `http://127.0.0.1:5174/ui-showcase.html?theme=light`。这是独立组件页，不启动正式应用、不连接图库。
- 对照：`design/preview.html?page=comps`；视觉令牌缺口及保守实现见 `doc/specs/reports/004.md`。

| 步骤 | 操作 | 预期结果 | 实际结果 |
|---|---|---|---|
| 1 | 从头浏览浅色页，再改成 `?theme=dark` 浏览；逐项对照组件稿 | 组件分组顺序一致，补充状态在末尾；深浅文字、边框、危险/成功状态可辨。已列出的令牌差异不冒充视觉定稿 | |
| 2 | 用 Tab 聚焦“不可用”按钮，再尝试鼠标点击、Enter、Space；查看加载按钮 | 不可用按钮仍可聚焦并显示原因提示，不能执行；加载按钮不能执行。相同内容切换加载时保留占位宽度 | |
| 3 | 在“角色名称”和下方补全输入框中用中文输入法输入；在候选阶段按 Enter | 候选确认不触发页面提交或采用补全。组合输入结束后，普通 Enter 才按组件规则处理 | |
| 4 | 打开下拉选择，使用上下方向键、Home、End、首字母跳转、Enter；再次打开后移动高亮并按 Esc | 移动高亮、跳转正确；Enter 提交，Esc 保留原值；关闭后焦点回到触发按钮 | |
| 5 | 用 Tab 进入选项组，方向键移动；再用方向键切换页签，按 Tab | 单选组只有一个 Tab 停靠点；方向键选中相邻可用项。页签切换后 Tab 进入对应内容区 | |
| 6 | 聚焦开关和复选框，按 Space；尝试不可用状态；操作滑块和步进器 | 开关/复选框按 Space 切换且不可用项不响应；滑块按步长调整，Shift 为十倍步长，Home/End 到边界；步进器可输入，越界值在提交时归入边界，上下键和加减按钮有效 | |
| 7 | 点击下方“右键菜单”；用方向键跨过“存为常用块”，在“移动到”按右键，再按左键、Esc；在旁边 Tag 上右击或用 Shift+F10 | 跳过不可用项；左右键进入/返回子菜单；Esc 一次关闭一层，最外层关闭后归还焦点。右键菜单可从鼠标和键盘打开 | |
| 8 | 将窗口调窄，在窗口右下边缘附近打开菜单/子菜单；点击菜单外 | 浮层翻转或约束在视口内；外部点击关闭整组菜单并归还焦点 | |
| 9 | 在补全框输入“铜色”，按上下键和 Enter；重复后按 Esc，再试“直接添加” | 输入框始终保留焦点，活动项高亮、采用结果正确；Esc 关闭，直接添加回调可触发 | |
| 10 | 打开“编辑一个 Tag”，反复按 Tab/Shift+Tab，按 Esc；重新打开后点外部 | 焦点进入并在浮层内循环；Esc/外部点击关闭后回到触发按钮 | |
| 11 | 打开“关闭已修改的标签？”；尝试点击背景或 Tab 到背景；聚焦“丢弃并关闭”后按 Enter，再用 Space 或鼠标明确确认；另开一次按 Esc | 默认焦点为“取消”；背景不可点击、不可聚焦；破坏性确认不会被 Enter 直接触发；明确确认可执行；Esc 等于取消并归还焦点 | |
| 12 | 点击下方“复制 Prompt”和“删除”产生通知，连续触发两条；悬停第一条或聚焦“撤销”，等超过 4 秒，再移开/移走焦点 | 通知在固定位置顺序显示，不抢焦点；悬停或焦点期间不消失，解除暂停后按剩余时长消失；撤销只执行一次 | |
| 13 | 悬停带提示的按钮约半秒，再移开、按下或滚动；用 Tab 聚焦同一按钮 | 悬停延迟出现，键盘聚焦立即出现；离开、按下、滚动立即隐藏；提示不关闭其他操作浮层 | |
| 14 | 激活 Tag；点击多选条“取消”；用鼠标拖动末尾面板分隔条，再用方向键、Home/End，最后双击 | Tag 可聚焦、可激活；多选条隐藏不推动内容；面板宽度受最小/最大限制，键盘有效，双击恢复 340。页面演示不持久化到用户设置 | |
| 15 | 改成 `?theme=system`，切换系统深浅主题；开启系统减少动态效果；再测试 `?theme=light&motion=off` | 系统主题变化即时应用；系统减少动态效果或应用关闭动效时，按钮/开关过渡立即完成 | |
| 16 | 使用 Windows 讲述人检查按钮原因、菜单、对话框、进度条、通知及危险横幅 | 控件名称和状态可读；进度为 38/100；通知礼貌播报，警告/危险横幅即时播报。展示占位名称为待设计文案，不能作为正式文案验收 | |
