# Tag 缓存管理手工验证

## 验证信息

- 变更：设置页新增 Tag 缓存搜索、筛选、译文/分类编辑和单条删除功能
- 目标操作系统：Windows 11
- 前置条件：已安装依赖；应用中至少存在 3 条由 Tag 整理或翻译产生的缓存；其中最好包含服饰、角色或画师 Tag
- 数据提醒：编辑与删除会修改本机 Tag 缓存。请先记录测试条目的原译文和分类，并选择可重新生成的缓存进行删除测试。

## 验证步骤

1. 运行 `npm run dev`，进入“设置”，点击左侧“Tag 缓存”。
   - 预期结果：页面显示搜索框、分类筛选、来源筛选、缓存总数和缓存列表；每条记录包含原 Tag、译文、分类、来源、编辑和删除操作。
   - 实际结果：

2. 在搜索框中分别输入一段原 Tag 和一段中文译文。
   - 预期结果：输入停止后列表自动刷新；原 Tag、显示名或译文包含搜索内容的记录会出现，总数与分页同步更新；清空搜索后恢复完整列表。
   - 实际结果：

3. 依次选择一个分类和一个来源筛选，并组合使用搜索条件。
   - 预期结果：列表只显示同时满足搜索、分类和来源条件的记录；没有结果时显示明确的空状态；恢复“全部分类”和“全部来源”后记录恢复。
   - 实际结果：

4. 选择一条记录点击“编辑”，修改译文和分类并保存；离开“Tag 缓存”后再次进入。
   - 预期结果：编辑状态只作用于当前行；保存成功后显示提示，记录立即展示新译文和分类，译文与分类来源均显示为“用户修改”；重新进入页面后修改仍然存在。
   - 实际结果：

5. 再次编辑刚才的记录，将译文和分类恢复为测试前记录的值并保存。
   - 预期结果：恢复后的值正确保存，不影响其他缓存记录或图片中已经保存的 Prompt。
   - 实际结果：

6. 选择一条可重新生成的缓存点击“删除”，先取消一次，再次点击并确认删除。
   - 预期结果：第一次取消后记录保持不变；确认时对话框说明不会修改图片 Prompt；确认后记录从列表消失、总数减少，搜索该 Tag 不再返回缓存。
   - 实际结果：

7. 缩窄应用窗口，并分别切换浅色与深色主题查看该页面。
   - 预期结果：筛选控件和记录内容会换行而不重叠或溢出；文本、分类标记、按钮和确认对话框在两种主题下均清晰可读。
