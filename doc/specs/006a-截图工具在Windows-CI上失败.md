# 006a 截图工具在 Windows CI 上失败

> 阶段：任务 006 的修复
>
> 执行者：工程负责人
>
> 分支：`main`

## 问题

推送 `f31949f` 之后，CI 的两个 Windows 组合在 `npm run screenshots:app` 这一步失败，日志里的错误是 `[Error: Unexpected viewport size]`。两个 macOS 组合通过，截图正常。

设计负责人的推测（**需要你核实，不要直接当成结论**）：GitHub 的 Windows 机器屏幕分辨率是 1024×768，Electron 创建 1240×760 的窗口时会把它限制在屏幕大小以内，于是页面的可视区域比预期小。macOS 机器的屏幕更大，所以不受影响。

## 要做的

1. 确认失败的真实原因。可以在本机把窗口限制在 1024×768 的条件下复现，或者在 CI 上打印实际的窗口尺寸和屏幕尺寸。
2. 修好，让截图的可视区域在任何屏幕尺寸下都是固定的 1240×760，不依赖运行机器的屏幕大小。不要通过放宽尺寸检查来"修好"。
3. 截图结果在本机保持不变：修复前后，本机截出的图片逐字节相同，或者逐条说明差异。

## 不做

- 不改截图的画面清单、页面和产品代码。
- 不改 CI 里截图以外的步骤。

## 验收标准

1. `npm run format:check`、`npm run typecheck`、`npm test`、`npm run build` 全部通过。
2. 用一个能代表 CI 条件的方式在本机复现了原来的失败，并证明修复后通过。说明你用了什么方式。
3. 汇报里写清楚原因。推送后 CI 的 Windows 组合能否通过，由设计负责人确认。
