# 004a 基础组件外观收尾

> 阶段：[重构计划](../rebuild-plan.md) 阶段 3，任务 004 的后续
>
> 执行者：工程负责人

## 背景

任务 004 的行为和结构已经验收。它的截图和界面稿差别较大，原因是令牌里缺少组件级的尺寸，你按规则都留成了 `TODO(design)`。这是对的。

设计负责人现在把这些令牌补进了 `design/tokens.css`（"细小的间距"到"可拖宽的面板"这几段），界面稿也已经改成使用它们。这个任务就是把它们套用到 `src/ui/`，让组件展示页和界面稿对得上。

## 范围

### 1. 套用新增的令牌

逐条处理 [004 的汇报](./reports/004.md) 第 4 节表格里的每一项，全部改成使用对应的令牌，然后删掉对应的 `TODO(design)` 注释。令牌旁边的注释写明了它用在哪里；仍然找不到对应令牌的，继续留 `TODO(design)` 并写进汇报，不要自己取值。

逐项的决定：

| 项目 | 决定 |
|---|---|
| 边线与焦点环 | 边线一律 `--bw`。焦点环 `--focus-w` 粗、离元素 `--focus-offset`，颜色 `--focus` |
| 加载指示 | 一个转动的圆环，直径 `--spin`、线宽 1.5px、一圈 `--dur-spin`。按钮加载时圆环在文字前面，**文字保留可见**（例如"生成中 2/4"），按钮宽度由调用方给的加载文案决定。动效关闭时圆环静止 |
| 输入框、下拉 | 左右内边距 `--ctl-pad-x`，前后缀与文字之间 `--ctl-gap`；小号用 `--sp-2`。出错说明放在输入框下方，这一点按你现在的做法 |
| 选项组 | 左右内边距 `--ctl-pad-x` |
| 页签 | 高 `--tab-h`，页签之间 `--tab-gap`，下划线 `--rule-w` |
| 开关、复选框 | 按 `--switch-*`、`--check`、`--r-check`。不可用时整体降到 `--text-off` 的灰，不改变形状 |
| 滑块 | 自己画轨道和圆钮，不用系统原生的外观：轨道 `--slider-track`，已选部分墨色；圆钮 `--slider-thumb`，内部是表面色，外面一圈 `--slider-ring` 的墨色。键盘行为保持不变 |
| 菜单、补全 | 最小宽度 `--menu-min-w` / `--complete-min-w`，行高 `--menu-row-h`，菜单内边距 `--sp-1`，项的左右内边距 `--ctl-pad-x`、圆角 `--r-tag`。**菜单里的快捷键是不带框的等宽小字**，颜色 `--text-3`；带框的快捷键标记只用在菜单以外的地方 |
| 编辑浮层 | 宽 `--popover-w`，内边距和行距都是 `--sp-3` |
| 对话框 | 宽 `--dialog-w`，内边距 `--sp-5`，标题行高 `--lh-title`，标题到正文 `--sp-2`，引文上下 `--sp-3`、左侧一条 `--rule-w` 的线，按钮区上方 `--sp-5` |
| 通知 | 高 `--toast-h`；左内边距 `--sp-4`，有操作时右 `--sp-2`、没有时右 `--sp-4`。位置确认为**窗口底部居中，离底 `--sp-6`** |
| 进度条 | 高 `--progress-h`，直角 |
| Tag | 内边距上 `--tag-pad-y`、下比上多 1px、左右 `--tag-pad-x`；圆点、文字、权重之间 `--ctl-gap`。分类圆点是一个直径 `--cat-dot` 的元素，不是字符，和英文那一行垂直居中 |
| 多选操作条 | 高 `--selbar-h`，左 `--sp-4`、右 `--sp-1`，按钮之间 `--sp-0` |
| 空状态 | 图形字号 `--empty-mark`，括号里的虚线方块边长 0.34em；说明文字最宽 `--empty-w`；标题到说明 `--sp-2`，图形下方和按钮上方 `--sp-4`，小字上方 `--sp-5` |
| 快捷键标记 | 内边距上下 `--sp-0`、左右 `--sp-1` |
| 可拖宽的面板 | 可点中的宽度 `--split-hit`；看得见的线是 `--bw` 的边线色，悬停、聚焦或拖动时变成 `--rule-w` 的墨色；方向键每次 `--split-step`，按住 Shift 乘以 4 |

### 3. 截图对照

重新生成浅色和深色的截图。另外输出一组**并排对照图**：左边是界面稿"组件"页的截图，右边是组件展示页前半部分的截图，同一主题一张，放在 `.codex-runs/004a/`。界面稿的截图用同一个离屏窗口去加载 `design/preview.html?page=comps` 得到（需要先起一个静态服务，脚本自己处理）。

## 不做

- 不改 `design/` 下的任何文件。
- 不改现有页面。

3. `src/ui/` 里剩余的 `TODO(design)` 逐条列在汇报里。
