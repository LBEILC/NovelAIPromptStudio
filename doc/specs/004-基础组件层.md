# 004 基础组件层

> 阶段：[重构计划](../rebuild-plan.md) 阶段 3
>
> 执行者：工程负责人
>
> 参照：`design/tokens.css`、`design/preview.html`（"组件"页是这次的主要依据）、[设计文档](../design.md) 2.11 节

## 目标

按界面稿实现一套自己的基础组件，放在 `src/ui/`，不依赖 `@lobehub/ui`。之后逐页迁移界面时，页面只用这里的组件。

**这个任务不改动任何现有页面。** 现有界面继续使用原来的组件库，行为和外观都不变。新组件在一个独立的"组件展示页"里呈现，用来和界面稿逐个对照。

## 看界面稿的方法

在仓库根目录运行 `python -m http.server 8766`，打开 `http://localhost:8766/design/preview.html?page=comps`。加 `&theme=dark` 看深色。其他页面（`page=wb`、`lib`、`set`、`acct`、`assets`、`empty`、`params`、`ai`）展示了这些组件在实际界面里的用法。

界面稿的 HTML 和 CSS 是为了表达样子写的，**可以参考它的数值和结构，但不要照搬它的写法**：它没有键盘行为、没有可访问性属性、状态是写死的。

## 硬性约束

- 用 TypeScript 和 TSX 写，通过 `npm run typecheck`。
- 颜色、字号、间距、圆角、尺寸、动效时长**只能**用 `design/tokens.css` 里的变量。应用直接引用这个文件，不复制、不另起变量。需要一个令牌里没有的值时，留 `TODO(design)` 并写进汇报，不要自己加。
- 样式用普通的 CSS 文件，不用 CSS-in-JS，不用 `!important`。类名加统一前缀，避免和现有 `src/styles.css` 互相影响。
- 不引入任何 UI 组件库或无样式的行为库。浮层用浏览器原生能力实现：`popover` 属性或 `<dialog>` 让浮层进入顶层，不靠 `z-index` 排层级；定位可以用 CSS 锚点定位，也可以自己算，但必须保证不超出窗口。应用固定运行在 Electron 43 上，不需要考虑其他浏览器。
- 图标继续用项目已有的 `lucide-react`，尺寸 16、线宽 1.5。界面稿里用文字符号代替的地方（下拉箭头、勾、加减号、关闭）换成对应的图标。
- 系统开启"减少动态效果"，或应用的动效设置为关闭时，所有过渡立刻完成。
- 文案不归你。组件不内置中文文案；需要的文字都由使用方传入。组件展示页里的示例文字照抄界面稿。

## 要做的组件

每个组件的样子和状态以界面稿"组件"页为准。下面只写界面稿表达不出来的行为要求。

| 组件 | 变体与状态 | 行为要求 |
|---|---|---|
| 按钮 | 默认、墨色、朱砂、安静、危险文字、危险描边；默认与小号；悬停、按下、焦点、不可用、加载中 | 加载中时不可点击，保持原来的宽度。不可用时仍然可以获得焦点并能说明原因（接收一个原因文字，用提示显示） |
| 输入框 | 默认、焦点、出错（带一行说明）、不可用；默认与小号；可带前后缀 | 中文输入法组合输入期间，不触发提交和快捷键 |
| 下拉选择 | 收起、展开、选中项 | 方向键移动，Home/End 跳到首尾，输入字符跳到匹配项，Enter 选中，Esc 关闭且不改变值，关闭后焦点回到触发处 |
| 选项组 | 一排互斥的小块，当前项墨色边框 | 是一组单选：方向键在组内移动并选中，Tab 进出整个组 |
| 页签 | 下划线样式 | 方向键切换，Tab 进入当前页签对应的内容 |
| 开关、复选框 | 关、开、焦点、不可用 | 空格切换；有可见的文字标签或可访问名称 |
| 滑块 | 带当前值 | 方向键按步长调整，Shift 加方向键按大步长，Home/End 到两端 |
| 步进器 | 减、值、加 | 值可以直接输入；上下方向键调整；可设最小、最大、步长 |
| 菜单与右键菜单 | 普通项、当前项、不可用项、危险项、分隔线、右侧快捷键文字、子菜单 | 方向键移动并跳过不可用项，右方向键进入子菜单、左方向键返回，Enter 执行，Esc 关闭一层，点外部关闭全部。关闭后焦点回到触发处。贴近窗口边缘时自动翻转方向 |
| 补全列表 | 每行：英文、中文、次数；末尾可以有"直接添加" | 输入框保持焦点，上下方向键移动高亮，Enter 采用，Esc 关闭。组合输入期间不响应 Enter |
| 浮层 | 承载任意内容，例如"编辑一个 Tag" | 打开时焦点进入浮层，Tab 在浮层内循环，Esc 或点外部关闭，关闭后焦点回到触发处 |
| 对话框 | 标题、正文、可选的引文、操作按钮 | 模态：打开时背景不可操作、不可获得焦点。默认焦点在取消上。Esc 等于取消。破坏性确认不能用 Enter 直接触发 |
| 通知 | 纯文字；带一个操作（例如"撤销"） | 从同一个位置依次出现，几秒后自动消失；鼠标悬停或有键盘焦点时不消失。对读屏软件是礼貌播报，不抢焦点 |
| 提示 | 一行文字或快捷键 | 悬停约半秒后出现，键盘聚焦时也出现；移开、按下、滚动时立刻消失 |
| 状态横幅 | 提示、警告、危险、成功；可带一个操作 | 危险和警告对读屏软件是即时播报 |
| 进度条 | 细线 | 有可访问的进度值 |
| Tag | 界面稿里列出的全部状态：默认、悬停、选中、有权重、负权重、翻译中、语法提示、新增、移走、被筛选隐藏、拖动中，以及"添加"占位 | 这里只做外观和单个 Tag 的可聚焦、可激活；拖拽排序、框选不在这个任务里 |
| 多选操作条 | 数量加一排操作 | 出现和消失不推动下面的内容 |
| 空状态 | 图形、标题、说明、操作、一行小字 | — |
| 可拖宽的面板 | 拖动分隔条改变宽度，有最小和最大值 | 分隔条可以获得焦点，方向键调整宽度；双击恢复默认宽度；宽度由使用方保存 |
| 快捷键标记 | 一个小方框里的按键名 | Windows 显示 Ctrl，macOS 显示 ⌘，由一处统一决定 |

主题：提供一个替代 `LobeProvider` 的外层组件，负责在 `<html>` 上设置 `data-theme`（跟随系统、浅色、深色）和动效偏好。这次只做出来，不接进现有应用。

## 组件展示页

- 一个独立的页面，把上面每个组件的每种状态都摆出来，排布和界面稿"组件"页一致，方便并排比较。支持用地址参数切换深浅主题。
- 它只用于开发和验收，**不能进入发布包**，也不能被应用的正式入口引用。
- 提供一条命令生成它的截图（浅色、深色各一张，整页），输出到 `.codex-runs/004/`。截图不要用模拟鼠标键盘的方式，用 Electron 的离屏窗口加自带的截图接口，或同等的方式。这条命令之后会在 CI 的两个平台上运行，所以不要依赖本机已安装的浏览器。

## 测试

- 行为要有自动测试：菜单的方向键与跳过不可用项、子菜单进出、对话框的焦点限制与默认焦点、浮层关闭后焦点归还、下拉选择的键盘操作、滑块与步进器的边界、通知的悬停不消失、输入法组合输入期间不提交。
- 需要 DOM 环境的测试可以加一个轻量的开发依赖，写进汇报。
- 现有的 288 个测试不能减少、不能改动。

## 不做

- 不改动 `src/App.jsx`、各页面文件、`src/styles.css`、`src/fonts.css` 和 `LobeProvider`。
- 不移除 `@lobehub/ui`。
- 不处理字体的随包分发（MiSans、Newsreader、IBM Plex Mono），那是单独的任务。组件只使用令牌里的字体变量，本机没有对应字体时会落到替补字体，这是预期的。
- 不做 Tag 的拖拽排序、框选、图片舞台、标题栏。
- 不做任何页面。

## 验收标准

1. `npm run format:check`、`npm run typecheck`、`npm test`、`npm run build` 全部通过。
2. 组件展示页的截图（浅色、深色）已生成。设计负责人会把它和界面稿并排比较；差异逐条在汇报里说明。
3. 构建出的应用里不包含组件展示页，现有界面没有任何变化。给出证据：构建产物的文件清单对比，或同等的证明。
4. `src/ui/` 里没有引用 `@lobehub/ui`、`antd`，没有 `!important`，没有写死的颜色值和像素字号（令牌变量以外的）。给出检查用的命令和结果。
5. 上面"测试"一节列出的每一项行为都有对应的测试。
