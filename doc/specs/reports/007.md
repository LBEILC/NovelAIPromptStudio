## 2. 改动了哪些文件

- `src/main.tsx`、`src/legacy/LegacyProviders.tsx`、`src/App.jsx`、`src/LobeProvider.jsx`：入口、旧提供者隔离、主题和外壳集成。
- `src/shell/`：标题栏和标志；`src/settings/`：五个设置分页、词典表格、样式及反馈测试。
- `src/state/{appearance,ai,storage,updates,dictionary}.ts*`：按领域管理读取、保存、错误、进度和订阅。外观提供共享 Context；其余设置状态原本多在旧 SettingsPage 内，本次一起移入独立模块。
- `src/ui/controls.tsx`、`ui.css`、`ui.test.tsx`：选项前缀与 TextArea；`src/shared/`：段落字体及 raw 导入类型。
- `electron/preferences.js` 及测试：默认主题、段落字体、保留既存主题色；`electron/main.js`：窗口覆盖层同步。
- `src/styles.css`：冲突变量改名、删除旧设置及竖栏样式；对应样式测试移除已废弃断言。
- 删除旧 `SettingsPage.jsx`、`TagCacheSettings.jsx`、`FeedbackCenter.jsx` 及旧反馈测试；入口从 JSX 迁移为 TSX。
- `electron/appScreenshots.js`、`scripts/app-screenshot-scenes.mjs`、`scripts/audit-ui.mjs`、CI：验证覆盖更新。
- `package.json`、lockfile、`LICENSES/RemixIcon/LICENSE`：按任务引入固定版本 `remixicon@4.9.1`，提供与界面稿一致的图标；许可随现有 LICENSES 打包规则分发。

`App.jsx` 从 2167 行减到 2114 行，减少 53 行（含空行，按文件换行计数）。设置页 props 从 7 个减少到 3 个：只留下跨页面的清空回收站、安装前保存、资源迁移后刷新回调。工作台和图片库 props 未作额外精简，功能不在本次迁移范围。

### 变量冲突与旧页面

旧样式中的 `--text`、`--danger`、`--font-ui`、`--font-mono`、`--ink`、`--ease-out` 全部改成 `--legacy-*`，包括引用；没有改设计令牌。修复了旧 Lobe 提供者按系统深色延迟覆盖显式浅色的冲突：向它传递统一解析后的主题。

旧页面截图保留原控件、布局和色调；可见变化是竖栏移到顶部，新标题栏占 44px，高度减少、横向空间增加。外壳颜色使用新令牌，旧工作区仍使用旧背景，两者存在设计预期允许的视觉差异。字体继续尊重旧默认或用户选择，未随本任务打包新字体。

## 5. 推断清单

- 用设置分页的 Activity 保留 AI 未保存草稿，恢复显示时不覆盖已载入草稿。
- 字体选择改用 004 Select 的键盘文字匹配；保留原字体发现/分类，不保留旧带搜索框和字体样张的自定义下拉。
- API Key 沿用旧的密码输入框与已保存提示，未额外增加界面稿的“更换”中间状态。
- AI 测试与模型读取遵循旧接口先保存的行为；不采用界面稿“先测试再保存”的隐含语义，以遵守不改变 IPC 的边界。
- 两种提示词分别恢复默认，保留旧交互。
- 词典保留旧分页和来源/更新时间详情；单条删除使用原确认流程。未增加没有后端功能的“重新翻译”。
- 回收站和安装更新仍由 App 执行跨工作台协调，其领域页面仅调用回调；不为减少 props 重写这些安全流程。
- 现有偏好默认 Geist/Geist Mono 保留，新字体作为 fallback；段落字体只取令牌首项保存。
