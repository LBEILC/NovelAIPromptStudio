## 1. 完成了什么

- 修复共享 Button 的图文间距。根因是 `--ctl-gap` 原来只作用于外层按钮，而图标和文字都在同一个 `.nps-button-label` 内；标签现在也使用 flex 和该令牌。图片库侧栏图文按钮同样使用 `--ctl-gap`，恢复按钮补上 `arrow-go-back-line`。
- 模型显示使用纯函数缩短已知名称，未知名称只去掉末尾八位十六进制标识。详情和筛选保留原名悬停提示。相同短名合并为一个复选项，勾选或取消同时操作全部原始名称；筛选条件条同步合并显示。
- 不改数据库及旧规则。旧智能收藏集仍按原始模型名精确匹配；只包含一个别名的旧规则在合并选项上显示半选，打开编辑不会自动扩大规则。
- 详情逐项省略缺失参数，全部缺失时移除该行，缺尺寸显示“尺寸未知”。兼容旧导入将空参数转成 0 的情况；源元数据明确记录的 0 和 Seed 0 仍显示。
- 收藏集管理移到网格上方，普通集合说明、智能集合规则和无规则说明均采用任务文案；全库无图片时仍保留当前收藏集的管理行。侧栏右键菜单提供重命名和危险色删除。
- 清空回收站移到说明行右端，使用安静危险小按钮，空回收站隐藏入口。
- 替换任务所列占位文案，同时更新不支持文件松开后的实际警告；永久删除按实际影响拼接工作台标签、未保存改动和释放空间说明。大图显示当前摞中的序号。

## 5. 推断清单

- 旧规则只选择某一原名时，用标准复选框半选表达，保持旧精确匹配；用户主动勾选合并项后才扩展到全部别名。新增规则继续存原始名称数组。
- 模型条件条及条件计数按可见短名分组，和筛选中的一个选项对应。
- 旧记录里无法从保留的源元数据证实的数值 0 视为缺失；源元数据中的 `steps`、`scale`、`cfg_scale`、`guidance` 明确提供 0 时保留显示。不迁移或改写旧记录。
- 收藏集右键菜单复用已有 ContextMenu，包括 Esc、焦点与危险色行为；菜单操作针对被右击的集合。
- 为满足“代码不再有文案占位”的验收要求，数据目录安全错误三处保留已有文字“无法定位数据目录以外或未列出的文件”，只移除占位外壳。它们不属于 012a 的界面文案表，已在执行过程中说明。
- 本机 `python` 不在 PATH，参考图使用 Node 静态服务提供相同的 `127.0.0.1:8766` 页面，通过独立 Electron 窗口截图。服务在截图结束后关闭。

## 6. 实现时核实

012a 没有单独标记的【实现时核实】条目。实际核实的根因和兼容性：

- 图文间距来自按钮内层没有布局间距，而非没有使用 Button。验收以 DOM Range 和图标边界测量实际距离，逐个比较 `--ctl-gap`，容差 1px。
- 数据库写入旧逻辑会把空数值转换为 0；显示层结合 `extra_json.parsed` 识别明确的零值。不修改数据库格式或读取规则。
- 模型简称只参与显示与选项分组；真实应用验收创建原名规则，确认仍只命中对应图片，再确认合并选择保存全部原名。
