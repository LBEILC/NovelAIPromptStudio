## 1. 完成内容

- 滚动提示验收使用 `TOOLTIP_SCROLL_CLOSE_MS = 100`。在同一次渲染器执行中先建立单调时钟期限，再派发 scroll，轮询提示 DOM 是否消失；迟到的定时器或结果不能把超时变成通过。产品实现直接卸载 Layer，没有退出动画，本次没有修改产品代码。
- 新增 `checkSoon`，界面反馈采用 `UI_FEEDBACK_MS = 200`，仍由原来的 check 记录一条布尔断言、上下文和失败状态。轮询只读取结果，不重复执行点击或其他副作用。
- CI 与 release 各自增加 `prepare-fonts`，运行在 `windows-latest` / Node 24：恢复缓存，未命中则运行原有 fonts，校验哈希，保存跨系统缓存。字体脚本仅依赖 Node 内置模块，准备任务无需 npm ci。
- 矩阵通过 needs 依赖字体任务，只恢复同一个精确键并执行 fonts:check。未命中时明确报 `MiSans font cache was not prepared; check the prepare-fonts job. Matrix jobs never download fonts.` 并退出 1。
- MiSans 4.003、SHA-256 `5daf8d5447bfd423cfdec94a0e07c53b205892223ccc6ea21b7b8a37248b44d9`、本机 fonts 行为均未改变。
- release 的准备任务没有分支条件：在当前标签运行中恢复可见缓存，若不可见就独立下载、校验、保存到当前 ref 的缓存作用域，随后同一次运行的 package 矩阵恢复。流程不依赖重构分支缓存已存在。

|---|---|---|

新增单元断言：60 毫秒内提交通过；110 毫秒才关闭失败；同步动作耗尽期限失败；异步谓词逾期返回 true 仍失败；React 提交期间节点暂缺可在期限内重试成功。既有业务验收标签/数目保留，改为有期限的布尔判定。
