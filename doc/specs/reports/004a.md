# 004a 工程汇报：基础组件外观收尾

## 1. 完成了什么

按任务定稿将 004 汇报中缺少的组件尺寸、边线、焦点环、内边距和动效改为使用 `design/tokens.css`。没有修改设计文件、现有业务页面或用户数据，没有新增依赖。

- 加载按钮改为圆环在前、文字可见；直径 `--spin`、线宽 1.5px、周期 `--dur-spin`，关闭动效时静止。
- 输入、下拉、选项、页签、开关、复选框、菜单、补全、浮层、对话框、通知、进度条、Tag、多选条、空状态和快捷键标记使用对应令牌。菜单快捷键去框；分类点改为真正的 5px 元素，与英文行居中。
- 滑块保留原生 `input[type=range]` 的语义和事件，通过 CSS 重绘轨道、已选段与圆钮。没有替换键盘逻辑或新增拖动逻辑。
- 可拖面板使用 `--split-hit`，分隔线按状态切换 `--bw` / `--rule-w`；默认方向键读取 `--split-step`，Shift 乘以 4。保留原有可选 `step` 接口和双击复位。
- 展示页保留原分组顺序，补齐双列间距、行距、标签栏和编辑表单排布；全部指定占位文案已替换。
- `npm run screenshots:ui` 现在输出到 `.codex-runs/004a/`，自动启动静态服务，用同一个 Electron 离屏窗口依次加载原始界面稿和展示页，生成浅深两套整页图、组件区裁切图、并排图及 JSON 证据。CI 上传路径同步更新。

## 5. 推断清单

1. 展示页前半部分定义为从“按钮”到“状态横幅与生成进度”的 9 个分区；对照图不包含后续交互区。裁掉参考页的开发导航外壳，以原尺寸并排比较。
2. 展示间距采用上述现有令牌组合；这是任务允许“不需要逐像素一致”的范围。输入示例缺口不通过凑值解决。
3. 截图为避免依赖外部字体服务，将界面稿的 Google Fonts 样式请求重定向到本地空样式，两侧都使用声明的系统后备字体。没有修改设计源文件、下载或替换字体。不同系统的字形及换行仍可能不同。
4. 滑块使用原生 range 加 `appearance: none` 实现自绘，不另建 ARIA 控件或拖动状态机。已选比例是运行时状态；轨道背景内缩半个圆钮，与浏览器原生圆钮中心运动范围对齐。18px 控件高度沿用稿中几何，用已有 `--switch-h` 表达。
5. 禁用开关的轨道以及选中复选框的实心部分改为 `--text-off`，保留圆钮/勾的表面色与位置，使开关状态仍可辨认；不使用原先整体 opacity。
6. 面板保留调用方显式 `step` 的优先权，未传时读取 CSS 令牌；Shift 倍率同时适用于这两种来源。拖动态通过元素属性表示，结束、取消和丢失捕获时清理，不改变宽度状态归属。
7. 添加 Tag 的底部多 1px 通过现有 `--bw` 表达；编辑表单仍保留原来 44px 标签列，步进器内部输入不额外套普通输入框的左右内边距。
8. 参考稿的分类选择色点需要扩展 Select 内容接口，留在差异报告中，没有在这次任务中扩展接口。独立快捷键提示继续使用带框标记。
9. 并排图高度不同的空白部分，直接采样展示图背景填充；未对捕获画面做缩放或颜色修饰。
