# 004 工程汇报：基础组件层

## 1. 完成内容

按任务新增独立的 `src/ui/` 组件层：按钮、输入、下拉选择、单选选项组、页签、开关、复选框、滑块、步进器、菜单/右键菜单及子菜单、补全、浮层、模态对话框、通知、提示、状态横幅、进度条、Tag、多选操作条、空状态、可拖宽面板、快捷键标记和主题容器。

组件采用 TypeScript、普通前缀 CSS 和已有 Lucide 图标。主题容器直接引用 `design/tokens.css`，维护 `<html>` 的主题、动效属性，监听系统变化。数值/选择/宽度由调用者持有；通知采用队列，暂停时保留剩余寿命。没有接入现有应用。

`npm run screenshots:ui` 将展示页单独构建到 `.codex-runs/004/site/`，使用安装的 Electron 离屏窗口输出浅深两张整页 PNG 和原生模态证据。未使用模拟鼠标/键盘，没有启动正式应用或访问图库。

## 5. 推断清单

1. 可复用控件采用受控值/回调；独立演示用局部 state，不持久化面板宽度或主题到用户设置。
2. 通知默认 4 秒、单条串行展示、暂停保留剩余时长；调用者可传 duration。定位临时方案见 TODO。
3. Select 的字符查找以 700ms 作为输入串间隔；方向键循环，跳过不可用项；取消不改变值。
4. Slider 的默认大步长为小步长十倍；Stepper 按 min 起算步进，提交时钳制、空白/无效输入恢复原值，可显式指定小数位数。
5. 菜单 Tab 关闭整组并将焦点交回触发处；右键菜单支持 Shift+F10/ContextMenu 键。子菜单通过点击或右方向键进入，没有增加悬停自动展开计时。
6. 破坏性对话框中，取消按钮以外的 Enter 均拦截；确认仍可用 Space 或鼠标明确激活。
7. Tooltip 用 manual popover，避免提示意外关闭操作菜单；延迟为任务明确给出的约半秒。Escape 只关闭当前提示。
8. 渲染坐标根据 anchor 和视口实测；先翻转，再钳制。过大内容在浮层内部滚动。
9. 分类文字通过 Tag 可访问名称暴露；按分类的示例行保留了可见类别名称。通用 Tag 未自行加入分类文案。
10. 展示页中需要展开呈现的菜单、对话框、提示、通知使用同一内容组件静态排布；真实顶层交互由后半段入口打开。扩展的 Select 状态行是只读样式示例。
11. 组件稿没有覆盖空状态和面板展示位置，追加在末尾；示例空状态文字从原稿空状态页取，其他未定标题使用占位。

## 6. 【实现时核实】及原生方案

任务没有另外标注字面上的【实现时核实】项目；原生能力、截图和发布隔离按验收要求实测。

- `popover="auto"`：下拉、菜单/右键菜单/子菜单、补全和编辑浮层；浏览器提供顶层与 light-dismiss。编辑浮层补充 Tab 循环。子菜单保持嵌套 DOM，由键盘逻辑负责逐层关闭。
- `popover="manual"`：提示和通知；提示自行控制悬停/焦点/滚动，通知队列不会因点击外部被浏览器关闭。
- `<dialog>.showModal()`：对话框；浏览器负责背景 inert 和模态顶层。默认焦点显式放在取消，cancel 事件映射取消。
- 定位：使用 `getBoundingClientRect` 与视口计算，不依赖 CSS 锚点定位，也不使用 z-index。ResizeObserver、窗口 resize 和滚动时重新计算。
- 限制：DOM 替身无法证明浏览器顶层和 inert；通过原生探针补证据，完整人机交互和读屏仍待手动验收。

没有发现行为要求与稿中形态无法并存的冲突。加载宽度保持、缺少的尺寸令牌和原生滑块导致外观差异，已逐项说明。没有擅自修改设计文件解决差异。
