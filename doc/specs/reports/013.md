## 数据与【实现时核实】

块类型及段落译文放在已有 `prompt_structure` 的可选 `block_annotations` 中，以 scope key、原文和起点关联，字段为 `raw/start/type/translation`。未增加表、列或 schema 版本。原始文本编辑按可对应的原文重用注释。

图片库记录使用现有 `generation_metadata.prompt_structure_json`；外部图片尚无图库记录，按绝对路径存入已有 `app_meta` 的 `workbench_structure:<path>`，值仍为 Prompt 结构。工作台会话继续使用已有 localStorage 键。重新打开原文件只叠加块注释，不把草稿文字写回图片；图库原始 Prompt 同样不因注释保存而被覆盖。文件改名后的路径记忆不会自动迁移。

旧版验证没有用新引擎代替：取真实 pre-native `f5d731…` 的 database.js，使用隔离安装的 sql.js 1.14.1 打开含新增注释的数据库，读取、改名、持久化，再由新引擎重新打开，检查注释及原文一致。命令：

```text
node scripts/verify-workbench-legacy.mjs .codex-runs/013/old-database.js .codex-runs/013/legacy/package.json
PASS: actual legacy sql.js opens, reads, renames and persists block type/paragraph annotations without changing prompt text
```

Tag 候选来自内置 DSO 52,475 条记录和本地用户 `tag_dictionary`。内置项包含英文键、译名和类别索引；用户表包含 tag、display_tag、translation、category、sources、flags、updated_at。两者均无使用次数字段，未伪造次数，也没有联网补查；候选次数暂留空。按英文和中文译名查找并合并用户条目，最多返回 30 条。
