# 012a 图片库界面收尾

> 阶段：[重构计划](../rebuild-plan.md) 阶段 4
>
> 执行者：工程负责人
>
> 分支：`rebuild/ui-1.0`
>
> 依据：[012 汇报](./reports/012.md) 第 4、5 节；设计负责人对 32 张并排对照图的验收

012 整体通过验收。下面是对照图里看到的问题，以及汇报里 `TODO(design)` 和占位文案的决定。

## 1. 按钮里图标和文字贴在一起

工具栏的"筛选""视图""导入"，详情栏的"加入收藏集""重命名"，底栏的"复制 Prompt"，多选条的"加入收藏集"，大图的"关闭""复制图片""另存为"，图标和文字之间都没有间隔。界面稿和 `src/ui` 的按钮都是 `--ctl-gap`。查清是这些地方没有用 `Button` 组件、还是组件在某种用法下丢了间隔，统一修好。给验收脚本加一条：图片库里所有同时有图标和文字的按钮，图标和文字之间的距离等于 `--ctl-gap`（允许 1 像素误差）。

另外"恢复"按钮照界面稿加上图标 `arrow-go-back-line`。

## 2. 模型名称

详情栏和筛选里直接显示了数据库里的原始名称，例如 `NovelAI Diffusion V4.5 4BDE2A90`。改为短名称：

- 去掉开头的 `NovelAI Diffusion `，去掉末尾的 8 位十六进制标识；
- `Full` 不写，`Curated` 保留：`V4.5`、`V4.5 Curated`、`V4`、`V4 Curated`、`V5`、`V3`；
- 认不出的名称照原样显示，只去掉末尾的十六进制标识；
- 鼠标悬停时提示原始名称。

筛选里短名称相同的几种原始名称合成一个选项，勾选它就是同时勾选这几种。写成一个纯函数并有测试（以上每种情况各一条）。012 以前保存的智能收藏集规则里用的是原始名称，读取时照常生效。

## 3. 缺失的参数不显示

一张图没有步数、引导强度或 Seed 时，详情栏现在显示成"0 步 · 引导 0 · Seed"。缺哪项就不显示哪项；三项都没有时这一行整行不显示。尺寸缺失时显示"尺寸未知"。

## 4. 收藏集的管理入口（TODO 1）

去掉侧栏选中项下方的"重命名""删除收藏集"按钮。改为：

- 打开一个收藏集时，网格上方有一行，和界面稿"智能收藏集"状态的那一行相同：
  - 智能收藏集：左边"规则"加条件，右边"编辑规则""重命名""删除收藏集"。没有任何条件时，左边写"没有规则，包含全部图片"。
  - 普通收藏集：左边写"手动整理，从详情栏或多选条加入图片"，右边"重命名""删除收藏集"。
- 侧栏里的收藏集右键菜单：重命名、删除收藏集（删除用危险颜色）。

## 5. 清空回收站（TODO 7）

从工具栏移到回收站说明那一行的右端，用安静的危险按钮（`btn danger sm` 的样式）："清空回收站"。回收站为空时不显示。

## 6. 占位文案（TODO 2 到 6、8）

| 位置 | 文案 |
|---|---|
| 新建收藏集对话框标题 | 新建收藏集 |
| 新建收藏集确认按钮 | 新建 |
| 新建、重命名时输入框的占位文字 | 收藏集名称 |
| 编辑智能收藏集规则的确认按钮 | 保存规则 |
| 排序选项 | 最近导入的在前、最早导入的在前、按名称排序 |
| 移入回收站后的通知（一张） | 已移入回收站 |
| 移入回收站后的通知（多张） | 已将 N 张图片移入回收站 |
| 拖入不支持的文件 | 只能导入 PNG、JPG、WEBP 图片和 ZIP |
| 永久删除时有图片正在工作台打开 | N 张正在工作台打开，删除后这些标签会关闭。 |
| 其中有未保存的改动 | 其中 M 个标签里有还没保存的改动，会一起丢弃。 |
| 永久删除时显示释放的空间 | 会释放 12.4 MB。 |

后三句按需要拼在永久删除对话框的说明后面，各占一句。

## 7. 大图的位置

一摞图片时，大图顶部名称后面照界面稿显示"832 × 1216 · 2 / 4"。
