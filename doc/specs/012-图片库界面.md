# 012 图片库界面

> 阶段：[重构计划](../rebuild-plan.md) 阶段 4
>
> 执行者：工程负责人
>
> 分支：`rebuild/ui-1.0`
>
> 前置：010（图库数据接口）、011（按"块"组织的 Prompt）
>
> 依据：[设计文档](../design.md) 2.9、2.11、2.13 节；界面稿 `design/preview.html?page=lib&sub=<状态>`（状态列表见设计文档 2.13 节，深浅两个主题都要对照）

## 目标

把图片库整页换成新的界面：不再使用 `@lobehub/ui`，用 `src/ui/` 的组件和 `design/tokens.css` 的令牌；数据走 010 的精简列表和按需详情；详情栏里的 Prompt 用 011 的块模型只读显示。现有的每一项能力都保留，除了下面"去掉"里列出的。

## 范围

### 1. 页面结构

- 左边常驻侧栏：全部图片、收藏集（标题右边有新建按钮）、智能收藏集、最底下是回收站。每项后面是数量。
- 中间：工具栏（搜索、筛选、视图、导入）、生效的筛选条件条、网格、底部的"多少组 · 多少张"。
- 右边详情栏，可以拖宽（用 `ResizablePanel`，宽度记住）。
- 新文件用 TSX，放在 `src/library/`。页面自己的状态从 `App.jsx` 里拆出来，放进 `src/state/`，做法和 007 一致。旧的 `src/GalleryPage.jsx` 及只有它用到的组件、样式，在新页面接上之后删除。

### 2. 网格

- **等高排列**（设计文档 2.13 节，界面稿的"横竖混排"状态）：每一行一样高，图片按自己的宽高比占宽度，一行排满，不裁切；最后一行不拉伸，用目标行高靠左排。目标行高是 `--thumb-row`，由"视图"里的大小调整（120 到 360 像素，每档 20）。宽高比限制在 `--thumb-ratio-min` 到 `--thumb-ratio-max` 之间，超出的用裁切。一摞图片按封面的比例。排行的计算写成不依赖界面的纯函数并有测试（输入：各图的宽高比、容器宽度、目标行高、间隔；输出：每行的高度和每张图的宽度）；缺少宽高的图按竖图 832 × 1216 处理。
- 用 010 的精简列表。只渲染看得见的那几行（窗口化），5000 张时滚动不卡，20000 张时能打开。窗口宽度或详情栏宽度变化时重新排行，选中的图保持在视野里。
- 升级后第一次打开图片库要建立缓存（010b）。这期间网格区域显示进度："正在整理图片库 1,200 / 5,000"，下面一行小字"只在升级后第一次打开时需要"，用 `Progress` 组件，进度来自 010b 的 `library:cards-progress` 事件（`window.studio.onLibraryCardCacheProgress`）；侧栏、导航和设置照常可用。建立完成后直接显示网格，不需要用户操作。不到 300 毫秒就完成时不显示进度。
- 大小、排序、合并方式都在"视图"浮层里，选择要记住（沿用现有的存储键，老用户的设置不丢）。原来保存的"缩略图大小"是宽度，换算成最接近的行高档位，换算规则写进汇报。
- 合并（分组）的计算沿用现有逻辑和后台线程，结果必须和现在一致。
- 一摞图片右上角显示张数。
- 单击选中；双击或 Enter 在工作台打开；空格打开大图；方向键移动选中项：左右按顺序走，上下找相邻一行里水平位置最接近的那张。
- 多选：Ctrl / Cmd 加单击、Shift 加单击、拖动框选、Ctrl / Cmd A、Esc 退出。多选时出现底部操作条：加入收藏集、移入回收站、取消；在某个普通收藏集里时多一项"移出这个收藏集"；在回收站里是恢复、永久删除、取消。

### 3. 搜索与筛选

- 搜索范围：文件名、Tag、译名、段落里的词。Ctrl / Cmd K 聚焦搜索框。
- 筛选浮层：包含的 Tag（全部都有 / 有任意一个）、排除的 Tag、模型、Vibe、导入时间（预设与自定义范围，选项沿用现有的）。
- 生效的条件逐条显示在工具栏下面，可以单独去掉，也可以一次清除。筛选按钮在有条件生效时显示条件数。
- "存为智能收藏集"把当前条件存下来；智能收藏集的"编辑规则"用同一个浮层。

### 4. 收藏集

- 新建、重命名、删除普通收藏集和智能收藏集；删除收藏集不删除图片，要有确认。
- 详情栏和多选条里的"加入收藏集"浮层：勾选加入或移出，可以当场新建并加入。

### 5. 详情栏

- 图片、名称、参数（尺寸、模型、步数、引导强度、Seed）、导入时间。
- 一摞图片时，图片下面是小图条：逐张切换、设为封面。
- 操作：加入收藏集、重命名、在文件夹中显示、移入回收站。
- Prompt 用 011 的块模型只读显示：基础 Prompt、各个角色、排除内容（默认收起）。Tag 块显示 Tag、译名、分类圆点、权重，超过两行时收起并显示"还有 N 个"，点开展开；段落块用段落字体显示原文，有译文时显示在下面。文字可以选中复制。
- 底部操作栏："复制 Prompt"、"在工作台打开"。"复制 Prompt"复制这张图完整的正向 Prompt：只有基础 Prompt 时与保存的原文逐字节相同；有角色 Prompt 时，拼接方式沿用工作台现有的"复制全部 Prompt"【实现时核实：把现有的拼接规则写进汇报】。排除内容不在其中，在"排除内容"一节的标题上单独提供复制。
- 详情按需取（010 的单张接口），切换选中项时不能闪一下空白：新内容到达之前保留上一张的内容。

### 6. 导入

- "导入"按钮打开文件选择（图片和 ZIP 一起）；小箭头里是"从剪贴板导入"；拖进窗口、在图片库里按 Ctrl / Cmd V 也能导入。
- ZIP 先打开"选择要导入的图片"对话框，行为沿用现有的（预览、已有的标出、全选、全不选）；里面的图片同样等高排列，行高固定为 `--thumb-row-zip`。
- 进度浮在网格底部：第几张 / 共几张、取消剩下的、跳过了几张重复的。完成后用通知说明导入了几张、跳过了几张、失败了几张。

### 7. 大图

盖住标题栏以下的整个窗口。缩放、100%、向左向右旋转、左右翻转、复制图片、另存为、在工作台打开；一摞图片时有小图条；左右方向键切换，Esc 关闭并把焦点还给原来的卡片。

### 8. 回收站

- 移入回收站后出现带"撤销"的通知。
- 回收站里：恢复、永久删除（确认对话框，默认焦点在"取消"）。工具栏里没有"导入"。

### 9. 空状态

空图片库、搜索和筛选没有结果，各一种，照界面稿。

空状态中间的图形改用 `design/identity/logo/symbol-empty.svg`（标准标志的括号加一个虚线方块），边长 `--empty-mark`，颜色 `--text-off`。现在 `Empty` 组件和组件展示页里是用字体里的花括号拼的，形状和标准标志不一样，一并换掉；标题栏的标志尺寸用 `--logo`。

### 10. 去掉

- 鼠标悬停弹出大图。
- "固定 / 取消固定预览面板"：详情栏一直固定在右边。

## 文案

界面稿里出现的文字就是定稿。界面稿里没有的，用 `【文案待定：…】` 占位并写进汇报。

## 验收断言

把下面每一条都加进 `npm run verify:app`，深浅两个主题都跑；截图加进 `npm run screenshots:app`，界面稿里的每个状态一张：

1. 侧栏各项的数量和演示数据一致；切换各项后网格内容正确。
2. 单击、双击、Enter、空格、方向键的行为。验收数据里要有横图、竖图和方图（仓库里的演示图全是竖图；横图和方图由验收脚本在临时目录里从演示图裁出来再导入，不进仓库）：同一行的卡片高度相同（相差不超过 1 像素），除最后一行外每行排满宽度，每张卡片的宽高比与图片一致（限制范围内）。
3. 多选的五种进入方式和 Esc；操作条的每个按钮。
4. 搜索能搜到段落里的词；每种筛选条件单独生效、组合生效、逐条去掉、一次清除。
5. 存为智能收藏集、编辑规则、重命名、删除。
6. 加入和移出普通收藏集，当场新建并加入。
7. 一摞图片的切换和设为封面，重启后封面还在。
8. 详情栏的"复制 Prompt"与工作台现有"复制全部 Prompt"的结果逐字节相同（用演示数据里的每一张图比对）；排除内容的复制与保存的原文逐字节相同。
9. 导入图片、导入 ZIP（挑选其中几张）、从剪贴板导入、重复图片被跳过、取消剩下的。文件选择用替身。
10. 大图的每个按钮、方向键、Esc 之后焦点回到原来的卡片。
11. 移入回收站、撤销、恢复、永久删除及其确认。
12. 两种空状态。
13. 关闭动效时以上各项照常工作。

顺带修一处：验收脚本为了核对等宽字体，会往"关于"页里临时插入一段 `blue_hair 1.25`，它被截进了 `about-light.png` / `about-dark.png`。核对完要移除，再截图。

另外用 `npm run benchmark:data-layer` 的 5000 张数据做一次测量，写进汇报：打开图片库到网格可以操作的时间、连续滚动到底的最长一帧、切换选中项到详情显示出来的时间。

- 工作台的任何改动。从图片库"在工作台打开"沿用现有的接口。
