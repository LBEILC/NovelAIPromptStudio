## 1. 产品定位

NovelAI Prompt Studio 是**以 Prompt 为核心的 NovelAI 本地创作客户端**。

它覆盖一个完整的循环：

1. 从一张 NovelAI 图片读出 Prompt 和全部生成参数。
2. 在本地看懂它、整理它、修改它。
3. 直接生成新图，并自动记下它是从哪张图、改了什么得来的。
4. 把值得留下的图存起来，以后再找出来接着用。

兼容 V4 / V4.5，以 V5 为最优先支持的对象。

软件负责把能力做出来，并把使用风险提示到位；怎么用是使用者自己的事。

## 2. 信息架构

```text
应用
├─ 工作台（默认）
├─ 图片库
├─ 素材        1.1 起
└─ 设置
```

导航放在标题栏那一行，设置入口在右上角。

| 图片的来路 | 行为 | 是否进图片库 |
| --- | --- | --- |
| 打开到工作台 | 从文件、拖放、剪贴板或图片库打开，成为一个工作台标签 | 否，但可以在工作台里一键存入 |
| 导入图片库 | 从文件、ZIP、拖放或剪贴板复制到资源目录 | 是 |
| 在软件里生成（1.1） | 生成结果挂在原图的版本下面 | 是，自动存入 |

## 3. 工作台

### 3.1 标签与会话

- 已有：同时打开多张图片，每个标签有独立的草稿和修改状态；重复打开同一来源时复用标签；重启后恢复标签顺序和草稿；关闭有修改的标签前确认。
- 1.0：工作台里的图可以一键存入图片库；图片下方一直显示生成参数（尺寸、模型、步数、引导强度、Seed）。
- 1.1：一个标签是一个**系列**：一张原图，加上从它改出来的各个版本。

### 3.2 Prompt 是由块组成的文档（1.0）

- **Tag 块**：一组 Tag，可以添加、删除、拖动排序、调权重、多选批量处理。已有的 Tag 编辑能力都保留在这里。
- **段落块**：一段自然语言，整段编辑、整段翻译，并标注用途（风格、主体、构图、角色、场景、分镜）。
- 导入时自动判断每一块的类型，用户可以手动改。V4 / V4.5 的 Prompt 表现为只有一个 Tag 块。
- 文档分为基础 Prompt、各个角色、排除内容三个部分。排除内容默认收起。
- 已有：读取 V4 / V4.5 的 PNG 元数据；区分基础与角色、正向与排除；按结构或按分类查看；原文、译文、对照三种显示；翻译和分类优先用内置词典与本地规则，AI 只补全剩下的，结果可以手动修正。
- 解析失败时保留原始文本，不能因为结构化失败丢内容。

### 3.3 Tag 提示（1.0）

输入时补全 Tag，可以用中文查找，数据来自内置词典。

### 3.4 复制与导出

- 已有：复制当前可见的正向 Prompt、全部正向 Prompt、基础 Prompt、指定角色的 Prompt、单个 Tag（纯文本或带权重）。复制结果保留原始顺序、权重和作用域，不混入译文或排除内容。
- 已有：识别图片里的 Vibe 数据并导出为 `.naiv4vibe`；查看、复制、下载图片（保留原始格式和元数据）。

### 3.5 生成（1.1 起）

- 用户自己配置 NovelAI 的 API Key。
- **永远从一张图出发**：把原图元数据里的参数整份拿来，只替换改动的部分。
- 生成前显示这次要消耗多少 Anlas。
- 请求严格串行，同一时间只有一个。
- 生成的图自动存入图片库。
- 编辑分层，在同一个页面里逐层展开：
  - 第一层（1.1）：Prompt、Seed、张数。
  - 第二层（1.2）：尺寸、步数、引导强度、采样器、角色位置、Vibe 与参考图。没有单独列出的参数原样保留，可以展开查看。
- 无人值守的连续生成：有，默认关闭，打开时提示一次风险。

### 3.6 版本（1.1 起）

- 两层：**版本**（一份 Prompt 与参数）和它下面的**若干张图**（不同 Seed）。
- Prompt 没改就生成，是给当前版本加一张图；改了再生成，是产生一个子版本；回到旧版本接着改，就分出一条岔路。
- 每个版本显示它相对上一版的改动：Tag 的增减、权重变化、哪个段落改了。
- 1.3：两个版本并排对比。

## 4. 图片库

- 已有：导入 PNG、JPG、JPEG、WEBP 和 NovelAI 导出的 ZIP；按内容指纹跳过重复；按完整 Prompt 把只差 Seed 的图折叠成组；组内浏览、头图、重命名、批量选择；普通收藏集和智能收藏集；筛选（时间、模型、Vibe、包含或排除的 Tag）；回收站，恢复和永久删除都有确认；大图预览支持缩放、旋转、翻转、复制、下载。
- 1.0：左侧常驻侧栏（全部图片、收藏集、智能收藏集，回收站在最底下）；详情栏用和工作台相同的方式只读显示 Prompt（带译文），可以直接复制 Prompt；搜索范围包括段落里的词。
- 1.1：生成记录；一个系列折叠成一摞。

## 5. 素材（1.1 起）

放可以反复使用的东西：

- **常用块**：存一整块 Prompt（例如一整段风格与画师 Tag，或一段分镜写法），一键插入。存的是块，不是单个 Tag。
- **角色**：保存的角色 Prompt。
- **Vibe**（1.2）：保存的 Vibe，在第二层参数里选用。

## 6. AI 与 Agent

- 已有：可选配置 OpenAI 兼容的 AI 服务，用于补全词典没有覆盖的 Tag 翻译和分类。
- **内置 AI 以"修改提案"的方式工作**：AI 给出对 Prompt 的改动，在文档里原位标出新增和移走的内容，由用户接受、放弃或逐项挑。不做聊天框。
  - 1.0：段落翻译；用中文写、转成英文段落（V5 也可以直接用中文写，所以这一项是可选的便利）。
  - 1.1：Tag 与段落互转；从基础 Prompt 拆分出角色并建立角色；按意图修改。
  - 之后：看图写 Prompt。
- **外部 Agent 可以接入**（1.1）：软件的每项能力都是不依赖界面的命令，提供命令行工具和配套的 Agent 技能，任何能运行命令的 Agent 都能读写 Prompt、搜索图片库、生成图片。
  - Agent 生成的图同样进入版本树，并标明来源。
  - 默认由 Agent 排好队、用户确认后串行生成；"Agent 直接生成"需要手动打开，打开时提示风险。
  - Agent 的 Anlas 花费上限：有，默认不启用，在引导接入时说明。

## 7. 设置与本地数据

- 已有：主题（跟随系统、浅色、深色）、动效偏好；界面字体与等宽字体；AI 服务配置与翻译、分类提示词；翻译词典（原"Tag 缓存"）的查看、搜索、修正、删除；图片库资源位置的查看与迁移；检查更新（Windows 应用内安装，macOS 引导到官方 Release）。
- 1.1：NovelAI 账号（API Key、Anlas 余额、无人值守开关）；Agent 接入（安装命令行工具和技能、花费上限）。
- API Key 等敏感信息只存进操作系统的安全存储。

## 8. 明确不做

- **需要在图上动手的编辑**：局部重绘、图生图、导演工具。搁置，前两层参数用起来之后再单独决定。
- **Git 式的分支管理**：不让用户创建分支、给分支起名、合并。版本关系只由"从哪一版改出来"自动形成。
- **并发生成**：请求只一个接一个地发。
- **AI 聊天框**：暂不做，先用修改提案。
- **单个 Tag 的资产库、Tag 收藏、Tag 关系图谱或统计面板**。
- **主题色**：1.0 起去掉这个设置。
- **修改原始图片的元数据**。
- **未经用户确认，把工作台草稿写回图片库里的资源**。

## 9. 数据安全与风险提示

- 原始图片不可变；图片库只管理用户主动导入或在软件里生成的副本。
- 数据迁移前创建可以恢复的备份；迁移失败时保留旧目录并给出明确提示。
- 删除区分"移入回收站"、"永久删除应用里的副本"和外部的原始文件。
- 文件清理只作用于经过验证的、由应用管理的资源目录。
- 不因为界面上去掉了旧功能而静默删除历史数据表或用户文件。
- 更新安装前保存工作台的标签与草稿；更新失败不能损坏图片库和偏好设置。
- 任何会花钱的操作，执行前显示要花多少。
- 在"关于"页和 README 里写明：这是非官方工具，与 NovelAI 没有隶属关系。
- 配置 API Key 时告知：这是通过用户自己的账号调用 NovelAI，是否符合其服务条款由用户自行判断并承担。README 里同样写明。
