# Lobe 视觉层级与颜色语义规范

> 状态：当前有效
>
> 最后核对：2026-07-27
>
> 产品边界：[当前产品边界](./two-page-workbench-gallery-refactor-plan.md)
>
> 组件工作流：[Lobe UI 前端开发 Skill](../.agents/skills/lobe-ui-frontend/SKILL.md)

## 1. 目标

NovelAI Prompt Studio 延续 Lobe UI 的设计语言，界面应安静、清晰、紧凑，适合长时间整理图片与编辑 Prompt。

本规范负责稳定的视觉语义，不记录易随依赖版本变化的组件 API。组件是否可用、从哪里导入、哪些接口已经弃用，以项目安装版本、本地类型定义和 Lobe UI Skill 为准。

## 2. 设计原则

- **连续表面优先**：导航、工作区与检查器首先是连续平面，不为每个信息块创建卡片。
- **主色只表示交互重点**：用于主操作、当前选择、焦点和真实链接。
- **语义色只表示状态**：成功、警告和错误不能被普通操作借用。
- **分类色独立于主题色**：切换主题色不能改变 Tag 分类含义。
- **内容文字保持稳定**：普通内容、按钮和 Tag 主文字使用中性色。
- **不只依赖颜色**：选择、错误和状态同时保留文字、图标、边框或形状线索。
- **深浅主题等价**：浅色与深色模式的信息层级、可读性和状态语义必须一致。

## 3. 表面层级

### Level 0：工作画布

使用主题布局背景，用于图片舞台、Prompt 内容区和设置页等大面积区域。

### Level 1：结构面板

使用容器背景，用于导航栏、顶部工具栏、工作台图片侧栏、图片库详情侧栏和设置导航。

### Level 2：轻交互表面

使用透明背景或低比例填充，用于列表悬停、Tag、筛选器和批量工具栏。

### Level 3：抬升表面

使用抬升背景，仅用于菜单、Popover、Modal、Toast、图片预览和其他真正浮在内容之上的元素。

固定面板中禁止连续嵌套卡片。优先用间距、细分隔线和轻微悬停底色组织内容。

## 4. 操作语义

| 类型 | 视觉 | 使用场景 |
| --- | --- | --- |
| Primary | 主题色实底、高对比文字 | 导入、确认、复制最终 Prompt |
| Default | 中性文字与中性表面 | 更换图片、恢复、普通编辑操作 |
| Text / Ghost | 透明背景、悬停轻填充 | 次级导航、显示文件、局部工具 |
| Danger | 危险色文字或实底 | 删除磁盘文件、不可恢复操作 |

- 同一视区通常只保留一个主要操作。
- “AI”“已编码”“已保存”等内容属性不能自动让按钮变成彩色。
- 破坏性菜单项和确认弹框必须同时使用危险色、明确动词和影响说明。
- 成功、警告、错误与进行中状态使用 Lobe 的 Message、Alert 或通知能力，不自行实现浏览器弹框。

## 5. Tag 分类配色

分类使用独立、低饱和色板。具体明暗由主题适配，不写死为主题 Primary。

| 分类 | 色相角色 |
| --- | --- |
| 画师年代 | Rose |
| 角色组成 | Cyan |
| 身份物种 | Blue |
| 外貌身体 | Teal |
| 服装配饰 | Purple |
| 动作表情 | Orange |
| 环境背景 | Green |
| 镜头光影 | Brown |
| 风格质量 | Gold |
| 未分类 | Neutral |

### Tag 规则

- 主文字使用中性主文字色。
- 分类通过低饱和背景、完整边框和小圆点表达。
- 权重使用弱化文字或对应分类色的低饱和版本。
- 选中状态使用主题色边框、轻背景与勾选标记。
- Undesired Content 使用低饱和危险色背景和边框。
- 语法异常使用警告图标与虚线边框，不改变分类归属。
- 翻译使用次级中性色。
- 选中、Undesired、语法异常和分类可以同时识别。

## 6. 布局与动效

- 工作台与图片库侧栏使用 Lobe 的可拖拽面板能力，保持挂载以保留内容状态。
- 收起、展开与调宽使用组件提供的状态和动效；业务 CSS 不覆盖其内部 transform、transition 或拖拽手柄布局。
- 长文件名在可用宽度内截断，固定操作始终可见。
- 工具栏允许自然换行；筛选分组不应依赖横向滚动才能使用。
- 动效只解释状态变化；跟随系统或关闭动效时，功能与可见反馈保持完整。

## 7. 组件约束

- 原生交互优先使用 `@lobehub/ui` 提供的组件，不混用浏览器 `alert`、自制菜单或另一套设计系统。
- Button、菜单、弹框、通知、图片预览、可拖拽侧栏等同类交互在两个页面保持一致。
- 基础交互原语优先采用当前版本公开的 Base UI 入口；更高层 Lobe 组件按包根导出使用。
- 不再新增已弃用的旧 Button API 或深层私有导入。
- 业务 CSS 只负责布局、尺寸和必要的产品语义，不重新实现组件完整状态。
- 遇到文档示例与本地类型不一致时，以本地安装版本为准，并按 Lobe UI Skill 的核对流程处理。

## 8. 验收清单

- 浅色、深色与跟随系统主题都能正确切换。
- 大面积固定区域不存在卡片套卡片。
- 普通按钮为中性色，主色与危险色只表达明确层级。
- Tag 分类、选择、Undesired 与语法异常互不混淆。
- 长文件名、窄窗口和大量 Tag 不遮挡固定操作。
- 菜单、弹框、通知、图片预览和侧栏使用统一 Lobe 交互。
- 侧栏收起、展开、调宽和重新选择内容均有连续反馈。
- Windows 与 macOS 共享视觉规则，仅保留符合平台习惯的窗口、菜单和快捷键差异。
