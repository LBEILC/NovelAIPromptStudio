# ZIP 图片选择导入手动验证

## 验证对象

- 变更：图库导入 ZIP 时先打开图片选择 Modal，使用图库式图片卡片、悬停名称和 Lobe 图片预览，支持单击多选、Shift 连选、Ctrl/Cmd 切换、从图片或空白处框选、全选和清空；普通图片仍直接导入。
- 提交：`0b760f0`、`6f05b4b`
- 目标操作系统：Windows 11、macOS。

## 前置条件

- 使用包含本次变更的开发版或打包版 NovelAI Prompt Studio。
- 准备一个至少包含 8 张不同 NovelAI PNG 的 ZIP，其中包含中文、空格、括号、嵌套目录和较长文件名。
- 再准备第二个包含至少 3 张 PNG 的 ZIP、一张 ZIP 外的普通图片，以及一张图库中已经存在的重复图片。
- 可选：在测试 ZIP 中加入一个扩展名为 `.png` 但内容不是 PNG 的文件，以及一个 TXT 文件。
- 记录验证前图库图片数量，避免把已有内容误认为本次导入结果。

## 验证步骤

1. 在图库点击“导入图片”，只选择一张或多张普通 PNG/JPG/WEBP，不选择 ZIP。
   - 预期结果：不打开 ZIP 选择 Modal，图片沿用原流程直接导入；进度和结果提示正常。
   - 实际结果：

2. 再次点击“导入图片”，选择包含 8 张以上 PNG 的 ZIP。
   - 预期结果：原生文件选择器关闭后打开标题为“选择要导入的图片”的宽幅 Modal；所有可读取 PNG 默认选中，主按钮显示准确的导入数量；非 PNG 条目不显示。
   - 实际结果：

3. 保持 Modal 打开，观察缩略图逐张出现，并在生成期间滚动网格。
   - 预期结果：Modal 无需等待全部缩略图完成即可操作；顶部持续显示预览进度，滚动和选择保持流畅；卡片采用与图库接近的方形封面裁切、紧凑间距和完整边框选中态。
   - 实际结果：

4. 悬停或键盘聚焦不同图片卡片，再点击卡片右上角的预览按钮；在预览层中切换前后图片、缩放并按 Esc 关闭。
   - 预期结果：文件名和目录默认不占据卡片高度，只在悬停或焦点态覆盖显示；预览层显示在 Modal 之上，使用最高 1280px 的受限预览图，可在所有已就绪图片间切换；关闭预览后返回原选择位置且选中状态不变。
   - 实际结果：

5. 普通单击几张图片，再使用 Shift 单击跨越一段连续图片。
   - 预期结果：普通单击切换单张选中状态；Shift 单击从上一次选择锚点追加连续范围；顶部、来源标题和导入按钮中的数量同步更新。
   - 实际结果：

6. 从图片像素区域和网格空白处分别开始拖动框选；再分别使用 Shift + 框选以及 Ctrl（Windows）/Command（macOS）+ 框选。
   - 预期结果：从图片本体按下并拖动时直接出现选择框，不出现浏览器原生图片拖拽虚影；普通框选以命中图片替换当前选择；Shift + 框选追加；Ctrl/Command + 框选切换命中项；选择框始终显示在 Modal 内容之上，松开后不会误触图片或预览按钮。
   - 实际结果：

7. 点击“清空”，确认没有 ZIP 外图片时导入按钮禁用；随后点击“全选”，再使用 Ctrl/Command + A。
   - 预期结果：清空后 ZIP 选择数为 0，导入按钮禁用；全选和 Ctrl/Command + A 都恢复全部可读取图片，数量准确。
   - 实际结果：

8. 使用 Tab 在图片、选择标记、预览、全选、清空、取消和导入按钮间移动，并用空格或 Enter 切换一张图片；按 Esc 关闭 Modal。
   - 预期结果：键盘焦点清晰可见，图片通过标准按钮语义切换选择，聚焦卡片时名称可见；Esc 取消整个预览会话，不导入任何图片，也不留下导入进度提示。
   - 实际结果：

9. 重新选择 ZIP；如果准备了伪 PNG，等待其预览失败。
   - 预期结果：伪 PNG 显示不可用状态和原因，自动从选择中排除且不能框选或单击选择；其他图片继续正常预览和选择。
   - 实际结果：

10. 只保留其中 3 张图片，点击“导入 3 张”。
   - 预期结果：Modal 关闭并显示正常导入进度；最终图库只新增所选 3 张，不导入未选图片；导入结果数量与实际一致。
   - 实际结果：

11. 同时选择两个 ZIP、一张 ZIP 外普通图片和一张已存在的重复图片。
    - 预期结果：Modal 按 ZIP 来源分组，两个来源各自显示准确选择数量；顶部明确说明 ZIP 外图片会同时导入；导入按钮数量等于所选 ZIP 图片加 ZIP 外图片；最终重复内容仍按原规则跳过。
    - 实际结果：

12. 从 Finder 或资源管理器把 ZIP 拖入图库，再重复一次选择和导入。
    - 预期结果：拖放入口与原生文件选择器进入同一选择 Modal，选择语义和导入结果完全一致。
    - 实际结果：

13. 在浅色、深色、跟随系统主题，以及完整、跟随系统、关闭动态效果下检查 Modal；把窗口缩到允许的最小尺寸，并在“跟随系统”模式下开启系统减少动态效果。
    - 预期结果：文字、边框、选中填色、焦点和警告状态均清晰；长文件名与目录被安全截断且可通过悬停标题查看；工具栏换行后不遮挡网格，Modal、底部按钮和最后一排图片均可访问；系统减少动态或关闭动态效果时不保留持续预览动画。
    - 实际结果：
