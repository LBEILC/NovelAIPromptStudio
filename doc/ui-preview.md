# 浏览器界面预览

在项目根目录运行：

```sh
npm run preview
```

使用支持 `node:sqlite` 和直接加载 TypeScript 的 Node.js 24，以及项目已有的依赖。打开终端打印的 `http://127.0.0.1:5180/preview/`。根网址也会转到预览页。5180 是固定端口，占用时启动失败；不影响使用 5173 的 `npm run dev`。在启动终端按 Ctrl+C，后台、Vite 和本机假服务一起退出，删除本次临时目录。

预览直接加载 `src/main.tsx`，使用产品的 React 组件、样式和设计令牌。保存界面代码后由 Vite 热更新，无须运行测试、CI 或产品构建。浏览器刷新保留本次预览的数据；重新启动则创建新数据。

## 数据和场景

启动会把 `demo/images/final/` 的 14 张演示图片导入独立的系统临时目录，建立两个手动收藏集、一个智能收藏集、三个工作台标签页、两个常用块、一个角色和一个回收站项目。一个标签页带有主线三版和分支两版，四张历史生成图另存入图片库，因此初始“全部图片”包含 18 张。首个标签页故意保留三处拼写错误，便于查看整理提案。词典包含内置词条、AI 译文和人工修改的译文。

左下角的“预览场景”可展开或收起，提供：

- 重置数据、空图片库、2000 条图片记录。
- 持久令牌和 AI 服务的未配置、已配置状态。
- 下一次生成返回 401、402、422（附服务器原因）、429、500，或模拟无法连接。
- 生成每张约 1.5 秒或 6 秒；导入慢速或恢复。
- 未订阅、V5 免费用量耗尽、Anlas 余额不足，以及恢复正常账号。
- 下一次 AI 请求失败。
- Agent 修改当前标签页的 Tag，或提交两个待确认生成任务。
- 浅色、深色、完整动效、关闭动效，使用产品“通用”页的外观设置命令。

拖入文件时，浏览器先上传到本次临时目录，再调用真实导入和工作台命令。“打开图片”和“导入”使用浏览器文件选择器。重复导入演示图会沿用产品的重复图片处理。支持图片与 ZIP 导入；文件选择器和上传单文件大小上限为 128 MB。

## 与桌面应用的差别

数据库、命令分发、导入、生成队列、版本、素材和偏好读写使用产品实现。生成请求连接本机假 NovelAI 服务，返回缩放后的演示图片；AI 请求连接本机假服务，延迟约一秒，返回固定的整理、中文起名、翻译及改写结果。它们用于观察界面状态，不代表真实服务的生成或理解能力。

预览不读取日常图库、账户或偏好目录。所有数据、上传文件、生成图和 ZIP 预览均位于本次临时目录。后台拒绝假服务之外的网络连接并记录尝试；媒体接口拒绝临时目录之外的路径。浏览器通过同源代理访问后台，页面的网络资源受 CSP 限制。

浏览器没有原生窗口按钮、原生菜单、系统文件对话框或拖动窗口行为。文本剪贴板使用浏览器能力，受浏览器权限限制；图片剪贴板和系统目录操作使用替身，资源目录迁移会返回取消。另存为使用浏览器下载。更新检查固定返回当前版本，Agent 安装只改变预览状态，不写入系统或修改 PATH。字体列表仅提供项目内置字体。

预览可能领先于已经实现的命令；新的界面调用尚未实现的命令时仍会返回真实的命令错误。浏览器及临时数据的性能只作参考，2000 条记录共享演示图片内容、使用独立文件硬链接。强制结束进程或断电不会执行退出清理；终端打印的 `nai-ui-preview-*` 目录可用于定位残留。

## 文件边界

`preview/start.mjs` 负责启动、HTTP/SSE 和场景接口，`session.mjs` 组装真实数据层并初始化数据，`handlers.mjs` 适配主进程命令，`services.mjs` 提供假服务与网络限制，`index.html` 和 `bridge.js` 提供浏览器入口和 `window.studio`。

图片协议只在预览的 Vite 转换插件中替换。产品源码和产品构建没有预览分支。预览文件不在类型检查、格式检查的既有目录或安装包文件列表中，也没有加入单测、应用验收或 CI；`npm run build` 仍只构建产品入口。
