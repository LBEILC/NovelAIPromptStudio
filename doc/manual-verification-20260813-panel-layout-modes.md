# 工作台与图片库侧栏布局模式手动验证

## 验证对象

- 变更：工作台左侧图片面板使用稳定布局收起，避免收起过程中压缩内部元素；图片库右侧预览面板默认浮动显示，并可通过图钉按钮固定为分栏。
- 首次验证提交：`2100f4f`。
- 首次验证结果：未通过。工作台左侧稳定布局外壳在宽屏下按 `34vw` 占位，内部面板受 `560px` 最大宽度限制，切换页面后会在两者之间留下空白；拖动分隔线后空白暂时消失。
- 首次修复提交：`734cf1c`。默认宽度改为限制在 `280px` 至 `560px`，解决稳定布局外壳与内部面板宽度不同产生的静态空白。
- 第二次验证结果：未通过。页面切换后首次收起时，内部图片仍随外壳宽度缩小；手动调宽后的第一次收起缺少完整动画，再次展开和收起后才符合预期；图片库预览面板同样复现。
- 本轮修复：两个面板在首次渲染时直接根据窗口宽度计算并传入受控像素宽度，不再等到用户拖拽后才从相对宽度切换为像素宽度；以下实际结果留待修复后复验填写。
- 目标操作系统：Windows 11。

## 前置条件

- 已执行 `npm ci`、`npm test` 和 `npm run build`。
- 工作台中至少打开一张包含 Prompt 的图片。
- 图片库中至少有 8 组图片，能够明显观察网格列数和滚动位置。
