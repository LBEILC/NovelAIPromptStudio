# 图库悬停预览关闭手动验证

## 待验证变更

- 变更：图库 `PopoverGroup` 双击关闭逻辑及无刷新关闭优化
- 涉及文件：`src/GalleryPage.jsx`、`src/GalleryPage.test.jsx`
- 验证范围：只关闭图库卡片的悬停小预览；不改变右侧详情面板状态

## 目标操作系统

- Windows 11

## 前置条件

1. 已安装项目依赖并完成生产构建。
2. 图片库中至少存在一张可以正常打开到工作台的图片。
3. 外观设置中的动效可使用任意模式。

## 验证步骤

1. 启动桌面应用，进入“图片库”，将指针停留在一张图片卡片上，直到悬停小预览出现。
   - 预期结果：卡片旁正常显示悬停小预览。
   - 实际结果：

2. 保持悬停小预览可见，双击同一张图片卡片。
   - 预期结果：图库不闪烁、不重新加载卡片，应用快速切换到工作台并打开对应图片；图库悬停小预览立即消失，不覆盖工作台。
   - 实际结果：

3. 从侧边导航返回“图片库”。
   - 预期结果：此前由单击事件打开的右侧详情面板仍保持原有图片与展开状态；悬停小预览不会无故残留。
   - 实际结果：
