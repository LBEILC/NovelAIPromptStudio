# 更新说明富文本验证

## 测试对象

- 变更：设置页“更新说明”使用 Lobe UI Markdown 渲染，兼容 GitHub 返回的 HTML 与 Markdown，并清理危险标签、事件属性和 URL。
- 目标系统：Windows 10/11 x64；如有可用环境，同时在 macOS 13 或更高版本检查排版一致性。

## 前置条件

- 使用包含本次变更的构建。
- GitHub 最新正式 Release 的说明至少包含二级标题、无序列表、粗体和行内代码；如需验证应用内自动更新返回的 HTML，请安装一个低于最新 Release 的 Windows 版本。
- 可以切换应用的深色与浅色主题。

## 验证步骤

1. 启动应用，进入“设置 > 关于与更新”，点击“检查更新”。
   - 预期结果：检查完成后显示“更新说明”，内容中不再出现原始的 `<h2>`、`<ul>`、`<li>`、`<strong>` 或 `<code>` 字符串。

2. 检查更新说明中的标题、列表、粗体和行内代码。
   - 预期结果：标题有清晰层级，列表带有项目符号，重点文字加粗，文件名或命令以行内代码样式显示；中文与英文混排可读且不溢出容器。
   - 实际结果：

3. 缩窄窗口并滚动一份超过显示区域的更新说明。
   - 预期结果：更新说明区域最高约 260px，区域内可独立滚动；长文本和长代码会换行，设置页其他操作保持可见且不发生横向溢出。
   - 实际结果：

4. 如果说明中包含指向本仓库的链接，点击该链接。
   - 预期结果：链接通过系统浏览器打开；应用窗口不会跳转到网页，也不会创建无应用外观的新 Electron 窗口。
   - 实际结果：
