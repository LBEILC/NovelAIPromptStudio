## 前提

1. 关闭其他应用实例。在仓库中运行 `npm run build`，再运行 `npm run start:demo`。全程只使用 `--profile=demo` 演示环境，不能运行不带 Profile 的应用进行本清单测试。
2. 使用 `demo/promo-v090/final/` 中可丢弃的图片准备演示图库，并在工作台打开至少三个标签。需要迁移位置时，提前创建一个仅用于此次验收的空文件夹。
3. AI 成功路径使用专用测试服务及测试 Key；没有测试服务时记录对应步骤未验证。不要把 Key 写入此文档。

## 步骤与预期

| 步骤 | 操作 | 预期结果 | 实际结果 |
| --- | --- | --- | --- |
| 1 | 启动演示环境，观察窗口顶部；依次进入工作台、图片库、设置。 | 顶部一行显示标志、两个导航入口、设置齿轮与系统窗口按钮；旧竖栏消失；导航当前项正确；图片标签仍留在工作台。 | |
| 2 | 拖动标题栏空白区，再双击空白区；点击导航和齿轮，并尝试从按钮处拖动。 | 空白区可拖动，双击切换最大化；按钮执行各自操作且不会拖动窗口；最大化后内容不被系统按钮遮盖。 | |
| 3 | 在外观页选择浅色、深色，快速往返切换；选择跟随系统后改变 Windows 的应用颜色模式。 | 新旧页面均跟随最终选择；系统按钮区域的底色和符号色同步；没有浅色页面配深色旧控件的情况。 | |
| 4 | 改变界面字体、等宽字体和段落字体，退出并用 `npm run start:demo` 重启。 | 界面与等宽字体立即改变并持久化；系统字体列表可用；段落字体选择保留，但本任务不将它应用到页面。 | |
| 5 | 依次选择完整、跟随系统、关闭动效；同时检查系统减少动画偏好的响应。 | 新组件遵循 004 组件规则：关闭及系统减少动画时不执行动画；控件和焦点仍可用。 | |
| 6 | 进入图片库设置，查看文件数和占用，打开资源文件夹；更改位置时先取消，再迁移到准备好的空目录。 | 显示的是演示环境的资源；取消不改位置；迁移有进度，完成后路径和统计更新，图片库及工作台图片仍正常；失败有提示。 | |
| 7 | 将两张演示图片移入回收站，其中一张在工作台保留修改草稿；从设置中清空回收站，先取消，再确认。 | 显示回收站数量；确认内容包含永久删除与工作台草稿影响；取消保留数据；确认后报告成功、跳过、失败数量，只关闭成功删除图片对应的标签，并刷新回收站数量。 | |
| 8 | 在 AI 服务输入地址、Key、模型和两种提示词，切换到其他设置分页再返回；执行保存并重启演示环境。 | 未保存草稿跨分页保留；保存成功后 Key 输入清空但显示已安全保存；重启保留配置；空 Key 保存保留原 Key。 | |
| 9 | 读取模型列表，选择一个模型，测试连接；再使用不可达的测试地址验证失败路径。 | 成功时提供模型和连接反馈，失败时显示错误并可重试。沿用旧行为：读取模型和测试连接会先保存当前 AI 配置。 | |
| 10 | 修改两种提示词，分别恢复默认，然后保存。 | 分别恢复对应默认内容，保存后重启保留；固定输出格式约束的说明仍显示。 | |
| 11 | 在翻译词典搜索原 Tag / 译文，切换分类和来源；在分类下拉用键盘移动并选择。 | 表格筛选正确；分类选项显示圆点和文字；无结果有空状态；筛选变化清除旧选择，圆点不会影响键盘文字匹配。 | |
| 12 | 编辑单条译文和分类，先取消再保存；勾选多条，批量修改分类，再删除（先取消、后确认）。数据超过一页时测试翻页。 | 编辑浮层显示原 Tag、来源和更新时间；取消不写入；保存、批量修改和删除按选择作用于全局词典；删除提示说明不改原图片 Prompt；翻页、选择本页和取消选择可用。 | |
| 13 | 在关于与更新切换自动检查，检查更新；有发布说明时打开说明对话框。按当前版本能力检查下载、重启安装入口。 | 显示实际版本及非官方声明；自动检查持久化；开发模式不下载安装；说明支持现有 Markdown/HTML；可安装版本重启前保存工作台标签与草稿。没有可更新版本时记录对应路径未验证。 | |
| 14 | 点击报告问题、提出建议、复制诊断信息与查看声明。 | 浏览器打开对应 GitHub 表单但不自动提交或附带数据；诊断内容只有版本和平台；声明对话框可打开并关闭，Remix Icon 等许可可读。字体说明待设计定稿的占位应如实记录。 | |
| 15 | 回到工作台测试 `Ctrl+I` 打开、`Ctrl+V` 粘贴图片、`Ctrl+W` 关闭标签、`Ctrl+Tab` 与 `Ctrl+Shift+Tab` 切换；在图片库测试 `Ctrl+I` 导入、`Ctrl+V` 导入剪贴板图片和 `Ctrl+K` 搜索。 | 与原行为一致；编辑文本时粘贴不被图片导入劫持；有修改的标签关闭前仍确认；原有应用菜单可用。 | |
| 16 | 最小化、恢复、最大化和关闭演示窗口；重启后检查导航、主题与保存的设置。 | 系统按钮正常，内容和按钮不重叠，已保存的数据与偏好仍在演示环境。 | |
